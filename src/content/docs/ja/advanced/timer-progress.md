ダイアログは、設定された秒数が経過すると自動的に閉じるタイマー機能によって開始できます。

`--timer (<seconds>)`


デフォルトのボタンを、ダイアログが終了コード `4` で閉じられるまでのカウントダウンタイマーに置き換えます。デフォルトのタイマー値は `10` 秒です。必要に応じて、オプションのパラメータ `<seconds>` を指定して、希望する値を設定できます。 `<seconds>` が 60 より大きい場合、カウントダウンは `HH:MM:SS` 形式で表示されます。例えば、280秒の場合、初期表示は `4:40` となります。

もし`--button1text`と組み合わせて使用する場合、デフォルトのボタンが表示されますが、タイマー開始から最初の3秒間は無効になります。その後、ボタンが有効になり、標準のボタン1を使用して、終了コード0でダイアログを閉じることができます。

`--hidetimerbar` は、進捗バーとカウントダウン表示を非表示にします。

これにより、デフォルトボタンが常に表示されるようになり、タイマーの有効期限が不明な状態で閉じることができないダイアログボックスの表示を防ぐことができます。

## 進捗状況バー

Dialogは、インタラクティブな進捗状況を表示するバーを備えており、[コマンドファイル](/ja/advanced/command-file)]を通じて動的に更新することができます。

`--progress [<int>]`

指定されたステップ数で、進行状況を示すプログレスバーを表示します。 値が指定されない場合は、デフォルトで10ステップが表示されます。

進行状況バーを進めるには、ダイアログコマンドファイルにコマンドを送信してください。

```sh
echo "progress: <int>" >> /var/tmp/dialog.log
```

`--progresstext <text>`

プログレスバーの下に表示される初期テキストを設定します。このテキストはいつでも更新可能です。

```sh
echo "progresstext: Installing software..." >> /var/tmp/dialog.log
```

### 進捗状況のテキスト配置。

`--progresstextalignment [left | right]`

プログレスバーの下に表示される進捗状況のテキストの水平方向の配置を設定します。デフォルトでは中央揃えです。
