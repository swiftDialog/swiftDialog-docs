ダイアログウィンドウのデフォルト設定では、画面の中央に表示され、移動できません。他のウィンドウは、このダイアログウィンドウの上に配置できます。以下のコマンドラインオプションを使用することで、この動作を変更できます。

どちらの選択肢も、互いに独立して利用することができます。

## ウィンドウの表示可否。

`-p` または `--ontop`

このオプションを使用すると、ダイアログウィンドウが常に最前面に表示されるように設定できます。

## ウィンドウの位置。

`-o` または `--moveable`

このオプションを使用すると、ウィンドウを画面上で自由に移動させることができます。

`--position [topleft | left | bottomleft | top | center/centre | bottom | topright | right | bottomright]`

ダイアログウィンドウを、画面上の指定された場所に配置します。

`--positionoffset <num>`

ウィンドウの端からのオフセットを設定します（画面の端とウィンドウの間の距離）。

`--position <x>,<y>`

ダイアログウィンドウを指定されたX座標とY座標の位置に表示します。例：`--position 100,200`

**注記：**
 - 画面の表示領域の左上隅が、座標 (0, 0) に位置します。
 - 表示される画面領域は、ドックやメニューバーが占有する領域を除きます。例えば、ドックが画面の左側に配置されている場合、基準点が内側にずれることがあります。


## ウィンドウサイズ

メッセージの内容に応じて、文字サイズをデフォルトよりも大きくしたり小さくしたりすることができます。また、異なるサイズのディスプレイで使用する場合でも、適切なサイズを表示するように調整できます。画像はそれに合わせて拡大縮小されます。テキストのフォントサイズは変わりません。

`-b` または `--big`

これにより、ウィンドウが通常よりも約25%大きく見え、アイコン表示領域がより広くなったように感じられます。

![image](https://user-images.githubusercontent.com/3598965/184131775-9ec40570-8e70-47ba-aecd-5561f6b6f54d.png)

`-s` または `--small`

これにより、ウィンドウが通常よりも約25%小さく見えるようになります。

![image](https://user-images.githubusercontent.com/3598965/184131853-94255fc7-b040-4b64-812b-bbe7e9bf412b.png)

## ウィンドウの外観

ダークモードまたはライトモードを強制的に設定することができます。設定されたモードは、ユーザーが現在選択している表示設定に関わらず、適用されます。

`--appearance dark` または `--appearance light`

## ミニモード

ミニモードは、特定の引数を指定することで有効になります。`--mini`

ミニモードでは、レイアウトが変更され、表示できるコンテンツが制限された小さなウィンドウが表示されます。 `--title` は、ウィンドウの上部に小さく中央に表示されます。または、`--title none` を使用して非表示にすることもできます。 `--message` には、最大4行のテキストを表示できます（それ以上の長いテキストは省略されます）。 `--icon` が表示されると、ウィンドウの左側に表示され、それ以外のコンテンツは右側に配置されます。 `--hideicon` と `--icon none` は有効です。 `--button1text` と `--button2text` は利用可能ですが、情報ボタンは表示されません。

![image](https://user-images.githubusercontent.com/3598965/184130942-8e0461e3-744d-4e69-89bc-6754cbd92abf.png)

`--progress`引数が使用される場合、ボタン領域は削除され、代わりにプログレスバーと、進行状況を示すテキストの1行が表示されます。ダイアログを閉じるには、コマンドファイルに`quit:`コマンドを渡す必要があります。

![image](https://user-images.githubusercontent.com/3598965/184131293-efe2e2a3-2a33-42cf-b397-941d053b2693.png)

## `--style` - あらかじめ設定されたウィンドウのスタイルを設定します。

ダイアログの表示方法を変更するために、デフォルトの値を変更します。

`--mini`以外のスタイルには、特別な属性は定義されていません。ウィンドウの見た目は、様々な引数を使用してウィンドウのプロパティを設定することで実現できます。

`centered`、`alert`、および`caution`は、`--title`の値を使用し、それをメッセージ領域のヘッダーとして追加した後、タイトルを非表示にします。これにより、タイトルが中央に表示されるアイコンの下に配置されます。

    "mini" は、機能的に "--mini" と同等です。"centered" を指定すると、コンテンツが中央に配置されるようになります。"alert" は、あらかじめ設定されたダイアログウィンドウ（300x300ピクセル、中央配置）を表示します。"caution" と "warning" は、アイコンが設定された "alert" と同じ動作をします。

例：`dialog --style alert`

<img width="412" alt="image" src="https://github.com/bartreardon/swiftDialog/assets/3598965/53add8af-3407-4152-b374-486db664b8e9">

これは、次のような操作と同じです：

```bash
dialog --title none --iconsize 80 --message "### An Important Message  \n\nThis contains important message content\n\nPlease read" --messagealignment centre --buttonstyle centre --centreicon --width 300 --height 300
```

## カスタムサイズ窓。

swiftDialogは、デフォルトの`--small`または`--big`オプションの代わりに、任意のサイズに設定できます。

`--width`と`--height`は、ダイアログのサイズを指定するために使用できます。コンテンツは、指定されたサイズに合わせて自動的に調整されます。

swiftDialogでは、現在の画面サイズに応じて動作を設定することができます。例えば、`--width 50%`を指定すると、ダイアログの幅が現在の画面解像度の50%に設定されます。`%`

![image](https://user-images.githubusercontent.com/3598965/129476080-a708fe71-c566-4caf-8323-899e5dbdcc2b.png)

## `--blurscreen`

`--blurscreen` は、すべての画面にぼやけた背景を重ねて表示し、ダイアログウィンドウを他のすべてのウィンドウの上に配置します。これにより、より集中したメッセージ表示が可能になるだけでなく、ユーザーが他のアプリケーションやデスクトップ環境とやり取りしないようにしたいワークフロー（例えば、初期設定時など）にも活用できます。


<img src="https://user-images.githubusercontent.com/8291873/229149297-ab060e52-120a-42bc-8a4c-1150b7d80ca2.png" width="500">


### `--ontop` の動作について：`--blurscreen` と既存のダイアログウィンドウとの関連。

既存のダイアログがアクティブな状態で、`--ontop`を使用すると、その後のダイアログがぼかしレイヤーの上に表示されます。これにより、バックグラウンドでダイアログを実行しながら、追加のダイアログを表示させることができます。ただし、これらのダイアログをプログラム的に操作する場合は、それぞれに対して一意のコマンドファイルを使用するように注意してください。`--blurscreen`

## `--showonallscreens`

この機能を使用すると、ダイアログウィンドウがすべての仮想デスクトップに表示されます。

もし複数のモニターを使用している場合、このダイアログは、起動されたモニターに関連するすべての仮想デスクトップに表示されます。
