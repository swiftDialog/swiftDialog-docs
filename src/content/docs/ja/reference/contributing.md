# 貢献する。

貢献は大変歓迎いたします。このプロジェクトを支援する方法はたくさんあり、コードの提供、フィードバック、または経済的な支援など、様々な形があります。

## コードへの貢献

コードの提供をご希望の場合は、リポジトリをフォークし、ブランチを作成して、プルリクエストを送信してください。

プルリクエストを提出する際は、既存のコードの構成にできる限り合わせ、内部の一貫性を保つようにしてください。コンパイルできる限り、フォーマットについては特に厳しくありませんが、もしコードが著しく乱れている場合は、修正をお願いするかもしれません。

## 問題の報告について。

- **機能に関するご要望:** もし何か機能に関するアイデアをお持ちで、ご自身で実装することが難しい場合は、課題としてご報告ください。私がそれを今後の開発計画に盛り込むかどうか検討します。
- **バグ報告:** もしバグを発見された場合は、問題の再現方法を記述した内容とともに、課題として報告してください。

[新しいフォームを作成したり、問題点を報告したりするには、こちらをクリックしてください。](https://github.com/swiftDialog/swiftDialog/issues/new/choose)

## 資金提供について

このプロジェクトが役立つと感じた場合、特にそれがあなたの仕事やビジネスをサポートしていると感じた場合は、ぜひ経済的なご支援をご検討ください。皆様からのご支援は、このプロジェクトの継続的な開発と維持に役立ちます。

- [GitHub Sponsors ](https://github.com/sponsors/bartreardon)
- [私にコーヒーをプレゼントしてくれませんか？](https://www.buymeacoffee.com/bartreardon)

このプロジェクトを商業的に利用している組織で、このプロジェクトに価値を感じている場合は、スポンサーとしてご協力いただければ幸いです。もちろん、義務ではありませんし、誰との関係にも影響はありませんが、プロジェクトの継続に役立ちます。

## 親切さについて（補足）

これは、私が個人的な興味から、空いた時間を使って開発しているプロジェクトです。もし改善点や、より良い方法をご存知でしたら、ぜひお聞かせください。プルリクエスト、問題報告、またはコメントなど、どのような形でも構いません。ただし、フィードバックは建設的で、敬意を払ったものにしていただきたいです。
