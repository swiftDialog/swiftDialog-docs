## 新機能・変更点


### 🚨 重要な変更点 🚨

swiftDialog 3.0 は、**macOS 15** 以降のバージョンが必要です。

macOS 14以前をサポートする必要がある場合は、[v2.5.6](https://github.com/swiftDialog/swiftDialog/releases/tag/v2.5.6)を使用してください。

### 新しいドキュメント。

すべてのドキュメントは、[https://swiftdialog.app](https://swiftdialog.app/getting-started/introduction/)] にて公開されています。


### macOS 26の視覚的なスタイルをサポートします。

このバージョンは、macOS 26上で動作させる場合、macOS 26のインターフェースを表示し、macOS 15上で動作させる場合、macOS 15のインターフェースを表示します。

macOS 26のブランドスタイルに合わせた新しい「スクエアル」アイコンが導入されました。これにより、既存のアイコンとの調和を図り、デザインの統一性を保つことができます。

古い「重要なメッセージ」という定型文が、タイトルとメッセージに使用されなくなりました。タイトルまたはメッセージを空欄にすると、メッセージとタイトルも空白になります。デフォルトのアイコンは、システムに組み込まれたアプリアイコンを使用し、SF記号は使用されません。

### 新製品 `--inspect-mode`

「インスペクトモード」は、macOSのファイルシステム内でリアルタイムの監視を可能にする、新たに組み込まれた機能です。AppleのFSEvents APIを活用してファイルシステムの状況を監視し、アプリケーションのインストール状況や、キャッシュフォルダ、ファイル、plistファイルの内容などを確認することで、コンプライアンスチェックを視覚的に把握できます。この機能は、デバイスの登録時、ソフトウェアの展開時、およびコンプライアンス監査時に特に有効です。

### 変更点：`/usr/local/bin/dialog`

`/usr/local/bin/dialog` は、現在、Swiftで記述されたコンパイル済みの`dialogcli`バイナリへのリンクになっています。以前は、コマンドライン処理とDialog.appアプリケーションバンドルの起動を処理するシェルスクリプトでした。

組み込みの`dialogcli`コマンドラインユーティリティは、実行時に`Dialog.app`アプリケーションバンドルが配置されている場所をインテリジェントに特定し、Dialogアプリケーションを別の場所に移動できるようにします。 実行するには、`/path/to/Dialog.app/Contents/MacOS/dialogcli`を実行してください。

この最初のリリースでは、基本的にはシェルスクリプトと同じ機能を提供しますが、今後さらに機能が追加される予定です。 将来的には、`Dialog.app/Contents/MacOS/Dialog`バイナリを直接実行する機能は廃止される可能性があります。

⚠️ _重要なお知らせ:_ このバージョンでは、`Dialog.app/Contents/MacOS/Dialog`を直接実行する際に、引数の数と順序が重要になります。簡潔にするため、フラグ（パラメータを持たない引数、例：`--ontop`）はコマンドの_最後_に指定してください。

### 構築モード

`--builder` モードは、通常の会話を作成する際の支援を目的としており、動作不良の修正や、新しいレイアウトへの対応など、いくつかの改善が加えられています。詳細は[こちら⟧](https://swiftdialog.app/builder/builder/)をご覧ください。

引数なしで `run` コマンドを実行すると、サンプル設定ユーティリティが起動します。`--inspect-mode`

### その他の追加事項。

 - "--position x,y" オプションを追加し、これにより、画面上の特定の座標を指定してウィンドウを表示できるようになりました。（#452）
 - リストアイテムにおけるアクションのサポートを追加しました。現在、サポートしているアクションはURLを開く機能のみです。 (課題番号: #472)
 - テキストフィールドのファイル選択機能に、初期ファイルパスを設定するオプションを追加しました。このオプションが指定されない場合は、デフォルトでユーザーのホームディレクトリが設定されます。 (課題番号: #451)
 - リストアイテムの項目に、`iconalpha` をオプションとして追加します。
 - オプションの`--loghistory`を追加しました。これは、`--displaylog`の製品番号#539で使用できます。
 - カスタムの未確定状態を示す直線プログレスバーを追加しました（macOS 26の直線プログレスバーは正常にアニメーションしないため、この対応が必要でした）。
 - `--image` と `--icon` は、カンマで区切られた複数の値をまとめて指定できるようになりました。例えば、`--image "/path/image1.png","/path/image2.png","/path/image3.png" #536` のように指定できます。
 - プルダウンリストに新しいオプションを追加しました。`searchable`
   - 例：
   ```
   dialog --selecttitle "Search Me",searchable --selectvalues "Apple,Banana,Cherry,Date,Elderberry,Fig,Grape,Honeydew,Kiwi,Lemon,Mango,Nectarine,Orange,Papaya,Quince,Raspberry,Strawberry,Tangerine,Ugli Fruit,Watermelon"
   ```
 - 起動時にサウンドを再生する機能を追加しました。ファイルまたはURLを指定できます。`--sound`
   - 例 `dialog --sound /System/Library/Sounds/Glass.aiff`
   - もし、非常に長い音声ファイルを読み込ませる場合は、`--showsoundcontrols` オプションを追加してください。
 - アニメーションGIFのサポートを実装しました（ついに）。
- リスト項目の選択を可能にする（一つまたは複数）。（課題番号：#465）
   - 新しい引数`--enablelistselect`により、クリック操作でリスト項目を選択できるようになります。選択状態は、標準出力（stdout）に`"<title>" : "<status"`として送信されます。
 - ボタンには、今や記号を表示したり、テキストのサイズを調整したりすることができます。
   - 新しい引数 `--button1symbol` `--button2symbol` `--infobuttonsymbol`。値として、1つのSFシンボル名を指定します。オプションの属性：位置、サイズ、スタイル、色。詳細については、`--help button1symbol` を参照してください。
     - 例：`--button1symbol sunrise.fill,multicolour,leading`
   - 新しい引数`--buttontextsize`は、設定したいテキストのサイズを表す数値を受け取ります。
   - ボタンのテキスト表示を無効にするには、ボタンのテキスト値を「`nil`」として指定できます。
 - ボタン1の機能を、スタック形式で、およびタイマー#520と連携させて有効にします。
 - swiftDialogのアイコンは、以下の方法でDockに表示できます。`--showdockicon`
   - ドックのアイコンは、カスタム画像に設定することができます。`--dockicon <img>`
   - ドックアイコンには、バッジを表示することができます。`--dockbadge <text>`
   - アイコンの表示状態やバッジは、コマンドファイルを通じて更新できます。
   - ドックアイコンは、アニメーションで強調表示することができます。通常モードでは1回、クリティカルモードでは複数回の跳ね返りアニメーションを表示します。
 - SF Symbols の表示形式が変化する際、対応するシンボルタイプ間でアニメーションが適用されるようになりました。
 - 追加オプション：`--hideotherapps` swiftDialogが起動すると、他のすべてのアプリケーションが非表示になります。
 - テキストの色をインラインで指定する機能を追加しました。指定方法は、`:colour[text]` の形式を使用します。例：`"Text can be :blue[blue] or :red[red]"`
   - あらゆるマークダウンテキスト領域、および`--title`と`--bannertitle`でも利用可能です。
 - タイトルと進捗状況のテキストに対して、左寄せおよび右寄せの表示に対応しました。
   - `--titlefont alignment=left`
   - `--progresstextalignment left`
