## 修正点。

- #484 - `name=` プロパティを、`--messagefont` のヘルプテキストに反映しました。
- #574 - 日付/時刻選択機能が、正しく動作するように実装されました。`--textfield`
- #608 - 再帰的に呼び出されるオプションが、最後の引数として渡された場合に引き起こしていたエラーが修正されました。
- #630 - `--ontop` ドックの配置を尊重します。
- #690 - 画像キャプションに関するコマンドファイル更新。
- #691 - プリセット5グループのヘッダー表示に関する問題。
- #696 - `--hidedefaultkeyboardaction`が正常に動作しないという既知の問題を修正しました。
- #689 - インスペクトモードでの最小値/最大値の表示機能。
- カードのテキストフィールドやトグルとのバインディングに、"Index out of range" エラーが発生するのを防ぐための補助機能 `boundedBinding` と `setIfInBounds` を追加しました。
- `ForEach(0..<collection.count)`から`ForEach(Array(collection.indices), id: \.self)`に切り替えました。これは、古いインデックスが原因で発生する問題を回避するためです。
- `--textfield ...,date` と `--textfield ...,time` の値を正しく返すように修正しました。
- `--alwaysreturninput` は、ボタンの操作だけでなく、**すべての**終了方法において、選択結果、リスト、またはJSON形式の結果を返します。
  - 注意：以前の動作（ボタンを押した場合のみ反応する）に依存しているスクリプトでは、新しい動作により出力結果が異なる場合があります。この機能を使用する際は、出力結果を確認する必要があるかもしれません。


## パフォーマンスの改善。

- **リモートからのデータ取得:** 画像やマークダウンのデータ取得には、明示的なタイムアウト設定 (10秒) が適用されます。
- **画像デコード:** 画像のデコード処理を、レンダリングごとに繰り返すのではなく、一度だけ行います。
- **SVG/PDFの読み込み** - レンダリングごとに読み込むのではなく、一度だけ読み込むようにします。`.task`
- **測定値の表示** - `GeometryReader` の代わりに `onGeometryChange` を使用してください。
- **ボタンごとのタイマー** - `enableOnTimer`が設定されている場合にのみ動作します。
- **JSON解析:** 起動時に一度だけ解析を行い、二度行うことはありません。


## 改良

### 引数ごとのJSON設定。

以前はカンマ区切りの値しか受け付けられなかった多くの設定項目が、現在はJSONオブジェクトとして指定できるようになりました。これにより、より直接的な制御が可能になり、特に複雑な設定を行う場合に役立ちます。

**サポートされている主張：**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

**例：**

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

詳細なJSONスキーマとサンプルについては、それぞれのドキュメントページをご参照ください。

### 日付選択の範囲。

日付と時刻の選択機能は、現在、`mindate=` および `maxdate=` というパラメータを使って、選択可能な日付の最小値と最大値を設定することができます。

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### 検査モードの一般的な設定オプション。

検査モードでは、JSONの設定ファイルにおいて、一般的なダイアログの動作を制御するためのオブジェクトを`options`サポートするようになりました。

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## 非推奨事項。

- `isdate` モディファイアは、`--textfield` に関して、`date` と `time` の採用により、非推奨となりました。
- JSON設定ファイル内で、引用符で囲まれた数値 (例: `"size": "40"`) が使用される場合、非推奨の警告が表示されるようになりました。代わりに、引用符なしの数値を代わりに利用してください。
