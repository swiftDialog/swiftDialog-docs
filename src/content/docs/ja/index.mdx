## クイックスタート例

```bash
# シンプルな通知
dialog --title "ようこそ" \
       --message "こんにちは、swiftDialogです！" \
       --icon "SF=star.fill"

# ユーザー入力フォーム
dialog --title "ユーザー情報" \
       --message "詳細を入力してください：" \
       --textfield "Name,prompt=お名前を入力してください" \
       --textfield "Email,prompt=メールアドレスを入力してください" \
       --button1text "送信"

# 進捗インジケーター
dialog --title "ソフトウェアをインストール中" \
       --message "セットアップするまでしばらくお待ちください..." \
       --progress 10 \
       --progresstext "インストールを開始しています..."
```
