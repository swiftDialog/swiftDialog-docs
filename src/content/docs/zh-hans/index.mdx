## 快速入门示例

```bash
# 简单通知
dialog --title "欢迎" \
       --message "你好，来自 swiftDialog！" \
       --icon "SF=star.fill"

# 用户输入表单
dialog --title "用户信息" \
       --message "请输入您的详细信息：" \
       --textfield "姓名,prompt=请输入您的姓名" \
       --textfield "电子邮件,prompt=请输入您的电子邮件" \
       --button1text "提交"

# 进度指示器
dialog --title "正在安装软件" \
       --message "请稍候，我们正在设置..." \
       --progress 10 \
       --progresstext "正在开始安装..."
```
