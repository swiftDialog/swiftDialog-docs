设置对话侧边栏的属性。

<img width="500" alt="image" src="/builder/builder_sidebar.png" />

## 属性

#### 信息框

将要显示的文本设置在信息框区域。

使用 Markdown 格式化文本内容。您还可以通过“从文件…”按钮或“URL/加载”字段，从 Markdown 文件或 URL 中加载信息框。构建器会将内容加载到预览区域，而导出功能则会引用该文件或 URL。使用“内联编辑”按钮可以返回到直接编辑文本的模式。

#### 可见的

设置侧边栏是否可见。

#### 信息文本

设置信息文本内容。

ℹ️ _注意：当`--infobutton`被使用时，`--infotext`将不会显示。_
