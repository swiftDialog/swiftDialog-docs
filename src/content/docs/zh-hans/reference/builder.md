## swiftDialog 构件工具包 (alpha 阶段)

swiftDialog 包含一个新命令 `--builder`。 当调用该命令时，会显示一个额外的窗口，允许您更新内容和对话框的属性，并实时查看结果。

然后，您可以生成 JSON 格式的数据，该数据可用于重新创建您设计的对话流程。

**请注意：此功能尚未完全完善，部分设置可能不可用，或者不会出现在生成的 JSON 文件中。开发工作正在进行中。**
