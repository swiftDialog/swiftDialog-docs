# 贡献

我们非常欢迎大家的贡献！支持这个项目有很多方式，无论是通过代码、反馈，还是资金支持，都非常欢迎。

## 代码贡献

如果您想贡献代码，请先复制（fork）这个代码仓库，创建一个分支，然后提交一个拉取请求（pull request）。

提交代码修改建议时，请尽量遵循现有的代码结构，以保持内部一致性。 我对代码格式的要求不是特别严格，只要能成功编译即可，但如果代码过于混乱，我可能会要求您进行整理。

## 报告问题

- **功能建议：** 如果您有任何功能的想法，但无法自己实现，请提交一个问题，我会将其添加到待办事项列表中。
- **错误报告：** 如果您发现任何错误，请将其报告为问题，并在报告中详细描述如何重现该问题。

[点击此处创建新的表格或报告问题](https://github.com/swiftDialog/swiftDialog/issues/new/choose)。

## 财务贡献

如果您觉得这个项目对您有所帮助，特别是如果它能支持您的工作或业务，请考虑提供财务支持。您的支持将有助于项目的持续开发和维护。

- [GitHub赞助计划](https://github.com/sponsors/bartreardon)
- [请帮我打赏一杯咖啡](https://www.buymeacoffee.com/bartreardon))

如果您的组织在商业上使用了这个项目，并且认为它有价值，欢迎您赞助。这并非强制性的，也不会影响我与任何人的互动，但赞助可以帮助项目持续发展。

## 关于善良的一段话

这是一个我利用业余时间维护的个人项目。如果您有任何改进建议，或者知道更好的方法，我非常乐意听取您的意见，无论是通过提交代码修改请求、问题反馈，还是简单的评论。我只希望您提出的反馈意见是建设性的，并且充满尊重。
