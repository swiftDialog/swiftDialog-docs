## 修复

- #484 - 恢复了`name=`属性在`--messagefont`帮助文本中的显示。
- #574 - 日期/时间选择器已正确连接。`--textfield`
- #608 - 可重复使用的选项不再因作为最后一个参数而导致程序崩溃。
- #630 - `--ontop` 尊重码头的位置摆放。
- #690 - 更新图像描述命令文件。
- #691 - 预设5组标题的渲染方式。
- #696 - 修复了当`--hidedefaultkeyboardaction`功能无法正常工作时的错误。
- #689 - 在检查模式下，最小化/最大化。
- 为 Card 组件中的文本框/开关绑定功能添加了 `boundedBinding` 和 `setIfInBounds` 辅助功能，以防止在跳过带有输入字段的卡片时出现“索引超出范围”的崩溃。
- 从`ForEach(0..<collection.count)`切换到`ForEach(Array(collection.indices), id: \.self)`，以防止索引过时的问题。
- 修复了 `--textfield ...,date` 和 `--textfield ...,time`，使其能够正确返回数值。
- `--alwaysreturninput` 在所有退出途径下（而不仅仅是按钮点击），都会返回选择/列表/JSON 结果。
  - 注意：依赖于旧行为（仅在按钮按下时才返回结果）的脚本可能会出现新的输出。如果使用此功能，可能需要进行检查。


## 性能改进

- **远程获取数据** - 图片和 Markdown 内容的获取受到明确的超时限制（10秒）。
- **图像解码：** 图像只进行一次解码，而不是每次渲染时都进行解码。
- **SVG/PDF 加载** - 通过 `.task` 仅加载一次，而不是每次渲染都加载。
- **查看尺寸** - 使用 `onGeometryChange` 代替 GeometryReader。
- **每个按钮的定时器** - 仅在`enableOnTimer`设置为“开启”状态时才运行。
- **JSON解析** - 启动时只解析一次，而不是两次。


## 改进

### 每个论点的 JSON 配置

以前只能接受逗号分隔值的参数，现在可以指定为JSON对象。这提供了更直接的控制方式，尤其适用于复杂的配置。

**支持的论点：**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

好的，请提供需要翻译的英文文本。

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

请参考各个文档页面，其中提供了详细的 JSON 模式和示例。

### 日期选择范围

日期和时间选择器现在可以通过 ``mindate=`` 和 ``maxdate=`` 两个参数来设置最小和最大日期范围。

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### 检查模式 - 常用选项

现在，检查模式支持在 JSON 配置文件中使用一个 `options` 对象，用于控制对话的总体行为。

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## 已弃用的功能

- 针对`--textfield`的`isdate`修饰符已被废弃，取而代之的是`date`和`time`。
- JSON配置文件中，如果数值被引号包围（例如：`"size": "40"`），现在会触发一个弃用警告。请使用未被引号包围的数值。
