## 最新动态


### 🚨 重要变更 🚨

swiftDialog 3.0 需要 **macOS 15** 或更高版本。

如果需要支持 macOS 14 或更早的版本，请使用 [v2.5.6](https://github.com/swiftDialog/swiftDialog/releases/tag/v2.5.6)。

### 新文档

所有文档现在都托管在[https://swiftdialog.app](https://swiftdialog.app/getting-started/introduction/))。


### 支持 macOS 26 的视觉风格

此版本在macOS 26系统上运行时，界面外观将采用macOS 26的设计风格；在macOS 15系统上运行时，界面外观将采用macOS 15的设计风格。

现在有一个新的“圆角矩形”图标，它符合macOS 26的品牌风格，以避免与其他“圆角矩形”图标混淆。

旧的“重要信息”的默认文本，用于标题和消息内容，已被移除。 如果标题或消息内容为空，将会显示空白的消息和标题。 默认图标现在使用内置的应用图标资源，而不是SF符号。

### 新产品 `--inspect-mode`

“检查模式”是一个新的内置功能，可以在macOS文件系统中实现实时监控。它跟踪文件系统的状态（利用苹果的FSEvents API），同时监控应用程序的安装过程，并检查缓存文件夹、文件以及plist内容，以可视化合规性检查结果。该功能特别设计用于设备注册、软件部署和合规性审计等场景。

### 对`/usr/local/bin/dialog`的修改

`/usr/local/bin/dialog` 现在是一个指向用 Swift 编写的编译后的 `dialogcli` 可执行文件的链接。 之前，这是一个 shell 脚本，用于处理命令行参数并启动 Dialog.app 应用包。

内置的`dialogcli`命令行工具能够智能地确定`Dialog.app`应用程序包的位置，从而使Dialog应用程序可以灵活地移动到不同的位置。可以通过运行`/path/to/Dialog.app/Contents/MacOS/dialogcli`来调用。

在这个初始版本中，它通常执行与 shell 脚本相同的操作，但未来会不断扩展其功能。 在未来的某个版本中，将不再支持直接运行 `Dialog.app/Contents/MacOS/Dialog` 二进制文件。

⚠️ _重要提示：_ 在本次版本中，当直接运行 `Dialog.app/Contents/MacOS/Dialog` 时，参数的数量和顺序非常重要。 为了简洁起见，请在命令的 _末尾_ 指定标志（不带参数的参数，例如 `--ontop`）。

### 构建模式

`--builder` 模式用于辅助构建常规对话，并且已经更新了一些修复，解决了某些功能失效的问题，并对部分新的布局进行了更新。 详细文档请查看 [此处](https://swiftdialog.app/builder/builder/)。

运行程序，不带任何参数，即可启动示例配置工具。`--inspect-mode`

### 其他补充内容

 - 新增功能，允许通过 `--position x,y` 参数指定屏幕上的精确位置。（问题 #452）
 - 为列表项添加对操作的支持。目前支持的操作仅限于打开URL。 (#472)
 - 为文本框文件选择功能添加文件路径选项，用于设置初始文件路径。 如果未指定，则默认为用户的主目录。 (#451)
 - 为列表项添加“iconalpha”选项。
 - 添加可选的`--loghistory`，可用于与`--displaylog` #539配合使用。
 - 添加了一个自定义的、不确定状态的线性进度条（这是必要的，因为macOS 26的线性进度条动画效果不正确）。
 - `--image` 和 `--icon` 现在可以接受多个值，这些值以逗号分隔的列表形式提供，例如：`--image "/path/image1.png","/path/image2.png","/path/image3.png" #536`
 - 新增了下拉列表中的一个选项。`searchable`
   - 示例：
   ```
   dialog --selecttitle "Search Me",searchable --selectvalues "Apple,Banana,Cherry,Date,Elderberry,Fig,Grape,Honeydew,Kiwi,Lemon,Mango,Nectarine,Orange,Papaya,Quince,Raspberry,Strawberry,Tangerine,Ugli Fruit,Watermelon"
   ```
 - 添加了`--sound`功能，可以在程序启动时播放声音。支持文件或URL。
   - 例子 `dialog --sound /System/Library/Sounds/Glass.aiff`
   - 如果传入一个非常大的音频文件，请添加 `--showsoundcontrols` 选项。
 - 添加了对动态 GIF 图像的支持（终于）。
- 允许用户选择列表项（可以选择一个或多个）。 #465
   - 新的参数 `--enablelistselect` 允许通过点击选择列表项。选择状态会以 `"<title>" : "<status"` 的形式发送到标准输出。
 - 现在，按钮可以包含符号，并且可以调整文本大小。
   - 新的参数 `--button1symbol` `--button2symbol` `--infobuttonsymbol`。 接受一个 SF 符号名称作为值。 可选属性：位置、大小、样式、颜色。 更多信息请参考 `--help button1symbol`。
     - 示例：`--button1symbol sunrise.fill,multicolour,leading`
   - 新的参数 `--buttontextsize` 接受一个数值，用于设置所需的文本大小。
   - 现在可以指定按钮文本的值，如果设置为`nil`，则可以禁用按钮文本。
 - 启用按钮1，采用堆叠样式，并与定时器 #520 相关联。
 - swiftDialog 的图标可以使用以下方法显示在 Dock 中：`--showdockicon`
   - 可以设置停靠栏的图标为自定义图片，具体方法是：`--dockicon <img>`
   - Dock栏图标可以使用一个角标。`--dockbadge <text>`
   - 图标的显示状态和徽标可以通过命令文件进行更新。
   - Dock 图标可以设置跳动效果：普通模式下跳动一次，关键模式下则跳动多次。
 - SF Symbols 的图标切换现在支持在兼容的图标类型之间进行动画效果。
 - 新增选项 `--hideotherapps`：当 swiftDialog 启动时，会隐藏所有其他应用程序。
 - 增加了对内联文本颜色的支持，使用`:colour[text]`格式。例如：`"Text can be :blue[blue] or :red[red]"`。
   - 支持在任何Markdown文本区域以及`--title`和`--bannertitle`中使用。
 - 增加了对标题和进度文本的左右对齐方式的支持。
   - `--titlefont alignment=left`
   - `--progresstextalignment left`
