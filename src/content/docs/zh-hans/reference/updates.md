Dialog 系统没有内置的更新功能。

为了保持对话内容的更新，有很多可供选择的方法。

## PKG 安装包或 ZIP 文件

最简单的方法是从[发布页面](https://github.com/bartreardon/Dialog-public/releases))手动下载 PKG 或 ZIP 文件，然后直接安装，或者将其导入到您选择的管理工具中。

## Installomator (软件名称，暂不翻译)

[Installomator](https://github.com/Installomator/Installomator)) 0.7版本包含了一个用于对话框的标签。

要使用 Installomator 安装 dialog，只需下载并运行 `./Installomator.sh dialog`，或者将 Installomator 脚本导入到您选择的管理工具中。
