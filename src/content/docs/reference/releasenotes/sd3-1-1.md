## What's New in swiftDialog 3.1.1

### Per-Argument JSON Configuration

swiftDialog 3.1.1 introduces **per-argument JSON configuration** — many arguments that previously accepted only comma-separated values can now be specified as JSON objects. This provides more direct control and is especially useful for complex configurations.

**Detection:** If a value parses as a JSON object, the JSON builder is used; otherwise, CSV parsing is applied.

**Supported arguments:**
- `--textfield` - Full field configuration with all modifiers including date/time pickers with bounds
- `--checkbox` - Checkbox with icon and button enablement
- `--listitem` - List item with nested icon objects
- `--selecttitle` / `--selectitem` - JSON-defined select list items
- `--titlefont` / `--messagefont` - Font configuration with colour, size, weight, shadow
- `--icon` / `--overlayicon` - Icon objects with symbols, colours, palettes, animations, light/dark variants
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol` - Button symbols with positioning and colours

**Examples:**

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

# Select list item
dialog --selectitem '{"title":"Region","values":["AU","US","UK"],"default":"AU","required":true}'

# Icon with light/dark variants
dialog --icon '{"light":{"sf":"sun.max"},"dark":{"sf":"moon"}}'

# Button symbol with positioning
dialog --button1symbol '{"name":"checkmark.circle","colour":"green","position":"trailing"}'
```

See individual documentation pages for detailed JSON schemas and examples.

### Date Picker Bounds

Date and time pickers now support **minimum and maximum date bounds** via the `mindate=` and `maxdate=` modifiers.

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
dialog --textfield "No earlier than today,date,mindate=20260928"
dialog --textfield "Before end of year,date,maxdate=20261231"
```

**Format:** Dates must be in `YYYYMMDD` format (region-proof). Separators are accepted and stripped (e.g., `2026-09-30` → `20260930`). Invalid dates are ignored and the bound is not applied.

**Note:** The `isdate` modifier has been deprecated in favour of `date` and `time`.

### Inspect Mode General Options

Inspect mode now supports an `options` object in the JSON configuration to control general dialog behaviour:

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```

This allows you to set window properties directly in the inspect config without needing to pass CLI arguments. Command-line flags take precedence over JSON options.

### dialogcli Fast-Path

The `dialog` CLI launcher now answers `--version`, `--licence`, and `--coffee` without launching the full app, providing faster feedback.

## Behaviour Changes

### `--alwaysreturninput` Returns on All Quit Paths

From 3.1.1, `--alwaysreturninput` returns select/list/JSON results on **all** quit paths, not just button press. This includes:
- Command-file quit
- Timer timeout
- Quit key press
- Killed process

**Migration:** Scripts relying on the old behaviour (only returning on button press) may see new output. Review your parsing logic if you use `--alwaysreturninput`.

### `--ontop` Respects Dock Position

The `--ontop` option now respects the dock position and positions the dialog within the screen frame (not on top of the dock). This reverts a deliberate decision from an earlier version.

### Date Picker Modifiers

The `isdate` modifier has been **deprecated** in favour of `date` and `time`. Update your scripts to use:
- `date` for date pickers
- `time` for time pickers
- `date,time` for both

## Bug Fixes

### Crash Prevention

- **Card textfield/toggle bindings** - Added `boundedBinding` and `setIfInBounds` helpers to prevent "Index out of range" crashes when advancing off cards with input fields
- **Range-based ForEach** - Switched from `ForEach(0..<collection.count)` to `ForEach(Array(collection.indices), id: \.self)` to prevent stale index traps
- **Preset5 group headers** - Fixed rendering order for deployment group headers ("Completed", "Pending Installation")
- **Image caption command** - Command-file `imagecaption:` now correctly updates `observedData.imageArray` instead of only writing to `appvars.imageCaptionArray`
- **Minimise/maximise in inspect mode** - Now handled explicitly in inspect mode command pipeline

### Input Handling

- **Repeatable options** - Fixed crash when repeatable options (`--selectvalues`, `--selecttitle`, `--textfield`, `--checkbox`, `--image`, `--listitem`, `--icon`, `--imagecaption`) are used as the final argument
- **Button bar keyboard action** - Fixed regression when `--hidedefaultkeyboardaction` was not working

### Date/Time Pickers

- **Date picker wiring** - Fixed `--textfield ...,date` and `--textfield ...,time` to correctly return values (previously was scaffolding that never returned values)

### Inspect Mode

- **Minimise/maximise commands** - Now handled in inspect mode command pipeline

## Deprecations

### `isdate` Modifier

The `isdate` modifier for `--textfield` has been deprecated in favour of `date` and `time`:

```bash
# Old (deprecated)
dialog --textfield "Start Date,isdate"

# New
dialog --textfield "Start Date,date"
```

### Quoted JSON Numeric Values

Quoted numeric values in JSON configuration (e.g., `"size": "40"`) now trigger a deprecation warning. Use unquoted numbers instead:

```json
# Old (deprecated)
{"titlefont": {"size": "40"}}

# New
{"titlefont": {"size": 40}}
```

## Performance Improvements

- **Remote fetches** - Bounded by explicit timeouts (10s) for images and markdown
- **Image decoding** - Images decode once instead of per-render
- **SVG/PDF loading** - Load once via `.task` instead of per-render
- **View measurements** - Use `onGeometryChange` instead of GeometryReader
- **Per-button timers** - Only run when `enableOnTimer` is set
- **JSON parsing** - Parsed once instead of twice at startup
