## Eigenschaften

#### Symbol

Ziehen Sie ein Bild oder eine Anwendung per Drag-and-Drop auf die Symboldarstellung im Bearbeitungsfenster, um den Symbolwert festzulegen

<img width="200" alt="image" src="/builder/builder_icon_drag.png" />

<img width="500" alt="image" src="/builder/builder_icon_drop.png" />

Sie können auch den Button "Auswählen" verwenden, um einen Dateiauswahl-Dialog zu öffnen, oder den Namen eines SF-Symbols im Format `sf=name` in das Textfeld für den Symbolwert eingeben (wobei `name` der Name eines gültigen SF-Symbols ist).

Alternativ können Sie auf das Vorschausymbol klicken, um das Popup-Fenster für SF-Symbole zu öffnen und einen SF-Symbolnamen und eine Farbe festlegen – der gleiche Auswahlmechanismus wird auch für [Listenelemente](/de/builder/listitems/) und [Kontrollkästchen](/de/builder/checkboxes/) verwendet. Das Overlay-Symbol verwendet ebenfalls denselben Auswahlmechanismus.

#### Sichtbar

Legt fest, ob das Symbol sichtbar ist oder nicht

#### Zentriert

Verschiebt das Symbol von der linken Seitenleiste in eine zentrale Position oberhalb des `--message`-Bereichs

#### Symbolgröße

Legen Sie die Größe des Symbols in Punkten fest

ℹ️ _HINWEIS: Wenn die eingestellte Größe nicht in den verfügbaren Platz passt, wird das Symbol auf die maximal verfügbare Größe reduziert, die in den Platz passt._

#### Icon Alpha

Legt den Transparenzwert für das Symbol fest. 0 = transparent, 1 = undurchsichtig

#### Überlagerung

Legen Sie die Symbolüberlagerung fest

ℹ️ _HINWEIS: Die Überlagerungsfunktion ist nicht verfügbar, wenn ein Symbol im zentrierten Modus verwendet wird._
