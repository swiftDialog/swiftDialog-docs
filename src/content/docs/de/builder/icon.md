## Eigenschaften

#### Icon

Ziehen Sie ein Bild oder eine Anwendung per Drag-and-Drop auf die Icon-Darstellung im Bearbeitungsfenster, um den Icon-Wert festzulegen

<img width="200" alt="image" src="/builder/builder_icon_drag.png" />

<img width="500" alt="image" src="/builder/builder_icon_drop.png" />

Sie können auch die Schaltfläche "Auswählen" verwenden, um einen Dateiauswahl-Dialog zu öffnen, oder den Namen eines SF-Symbols im Format `sf=name` in das Textfeld für den Symbolwert eingeben (wobei `name` der Name eines gültigen SF-Symbols ist).

Alternativ können Sie auf die Icon-Vorschau klicken, um das Popup-Fenster für SF-Symbole zu öffnen und einen SF-Symbolnamen und eine Farbe festlegen – der gleiche Auswahlmechanismus wird auch für [Listenelemente](/de/builder/listitems/) und [Kontrollkästchen](/de/builder/checkboxes/) verwendet. Das Overlay-Symbol verwendet ebenfalls denselben Auswahlmechanismus.

#### Sichtbar

Legt fest, ob das Icon sichtbar ist oder nicht

#### Zentriert

Verschiebt das Icon von der linken Seitenleiste in eine zentrale Position oberhalb des `--message`-Bereichs

#### Icon-Größe

Legen Sie die Größe des Icons in Punkten fest

ℹ️ _HINWEIS: Wenn die eingestellte Größe nicht in den verfügbaren Platz passt, wird das Icon auf die maximal verfügbare Größe reduziert, die in den Platz passt._

#### Icon Alpha

Legt den Transparenzwert für das Icon fest. 0 = transparent, 1 = undurchsichtig

#### Überlagerung

Legen Sie die Icon-Überlagerung fest

ℹ️ _HINWEIS: Die Überlagerungsfunktion ist nicht verfügbar, wenn ein Icon im zentrierten Modus verwendet wird._
