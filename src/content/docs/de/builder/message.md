### Eigenschaften

Die folgenden Eigenschaften können eingestellt werden. Klicken Sie auf die Schaltfläche "Zurücksetzen", um diese Einstellungen auf die Standardwerte zurückzusetzen

#### Textausrichtung

Positioniert den Text linksbündig, zentriert oder rechtsbündig

#### Vertikale Position

Wenn diese Option aktiviert ist, wird die vertikale Position auf zentriert eingestellt, anstatt auf oben ausgerichtet

#### Farbe

Legt die Farbe der Nachricht fest

#### Markdown-Quelldatei

Neben der direkten Eingabe des Textes können Sie ihn auch aus einer Markdown-Datei oder einer URL laden, indem Sie den Button "**Datei auswählen…**" oder das Feld "**URL / Laden**" verwenden. Der Editor lädt den Inhalt in die Vorschau, während die exportierte JSON-Datei / der Befehl auf die Datei oder URL verweist (so dass sie zur Laufzeit abgerufen wird). Verwenden Sie die Option "**Direkt bearbeiten**", um zur direkten Textbearbeitung zurückzukehren.

ℹ️ _HINWEIS: Schriftartänderungen sind nicht möglich._
