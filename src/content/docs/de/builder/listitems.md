Fügen Sie einen oder mehrere `--listitem` Einträge hinzu

<img width="500" alt="image" src="/builder/builder_listitems.png" />

Klicken Sie auf das `[+]`-Symbol, um einen neuen Listeneintrag hinzuzufügen

Klicken Sie auf das Papierkorbsymbol, um einen bestimmten Eintrag in der Liste zu löschen

Ziehen Sie den Griff (☰) links von einer Zeile, um die Einträge neu anzuordnen

<img width="500" alt="image" src="/builder/builder_listitems_populated.png" />

## Eigenschaften

#### Zeigen

Zeigt oder verbirgt den Bereich für Listenelemente

#### Symbol

Legen Sie ein Symbol für das Listenelement fest

Ziehen Sie eine Bilddatei oder ein Anwendungs-Bundle auf den Bereich zur Vorschau des Symbols, um den Wert des Symbols festzulegen

Klicken Sie auf den Bereich zur Vorschau der Symbole, um das Popup-Fenster für die SF-Symbole anzuzeigen. Hier können Sie den Wert und die Farbe des SF-Symbols festlegen

<img width="200" alt="image" src="/builder/builder_listitem_sfsymbol.png" />

#### Titel

Legt den Wert des Titels für das Listenelement fest

#### Untertitel

Legt den Untertitelwert für das Listenelement fest

#### Status-Text

Legt den Status-Text für das Listenelement fest

#### Symbol für den Status

Legt das Status-Symbol für das Listenelement auf einen der definierten Werte fest

Wenn Sie das `progress`-Symbol für den Status verwenden, können Sie mit dem Schieberegler eine Vorschau anzeigen oder den anfänglichen Fortschrittszustand festlegen
