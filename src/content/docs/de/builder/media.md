Konfigurieren Sie Web- oder Videoinhalte

<img width="500" alt="image" src="/builder/builder_media.png" />

### Video

Klicken Sie auf "Auswählen", um einen Dialog zur Dateiauswahl zu öffnen

Wählen Sie "Aktivieren", um den Bereich für die Videoanzeige anzuzeigen

Wählen Sie "Automatische Wiedergabe", um den Wert für die automatische Wiedergabe festzulegen

### Web

Verwenden Sie den Schalter, um die Anzeige von Webinhalten zu aktivieren oder zu deaktivieren

Geben Sie die gewünschte URL ein, um sie anzuzeigen
