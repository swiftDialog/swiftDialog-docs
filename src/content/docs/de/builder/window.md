## Eigenschaften

#### Fensterhöhe

Legen Sie die gewünschte Fensterhöhe fest

#### Fensterbreite

Legen Sie die gewünschte Fensterbreite fest

#### Vordefinierte Größen

Verwenden Sie eine der vordefinierten Größen, entweder "klein" oder "groß"

#### Fensterbedientasten

Aktivieren Sie die Fenster-Steuerungen (macOS: Schließen, Minimieren, Maximieren).

#### Unschärfe im Hintergrund

Aktivieren Sie die Hintergrundunschärfe-Ebene

#### Hintergrundbild für den Bildschirm

Legt ein Vollbild-Hintergrundbild fest, das hinter dem Dialogfenster angezeigt wird (`--screenbackground`). Aktivieren Sie diese Option und wählen Sie ein Bild mit der Schaltfläche **Auswählen** aus, oder geben Sie einen Pfad/eine URL ein. Im Gegensatz zum Eintrag **Hintergrundbild** weiter unten (ein Wasserzeichen *innerhalb* des Fensters) füllt diese Einstellung den gesamten Bildschirm hinter dem Dialog aus.

#### Beweglich

Legen Sie fest, ob das Fenster verschoben werden kann oder ob es an einer festen Position fixiert ist

#### Druck von oben

Legen Sie fest, ob das Fenster immer im Vordergrund aller anderen Fenster angezeigt wird

#### Fortschrittsanzeige

Aktiviert die Fortschrittsanzeige

Legen Sie die Anzahl der verfügbaren Fortschrittsschritte fest. Der Standardwert ist 100

#### Hintergrundbild

Legt das Hintergrundbild des Fensters fest

Klicken Sie auf die Schaltfläche "Auswählen", um einen Dateiauswahldialog zu öffnen, oder ziehen Sie ein Bild vom Finder per Drag-and-Drop in den Bereich zur Vorschau des Bildes

Legen Sie die Eigenschaften "Füllung" und "Skalierung" entsprechend auf `fill` oder `fit` fest

Verwenden Sie den Schieberegler, um die Transparenz des Bildes einzustellen

Legen Sie die Position fest, an der das Bild angezeigt werden soll (dies ist am effektivsten, wenn das Bild kleiner ist als die Fenstergröße).
