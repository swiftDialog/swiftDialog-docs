Legen Sie die Eigenschaften der Dialog-Seitenleiste fest

<img width="500" alt="image" src="/builder/builder_sidebar.png" />

## Eigenschaften

#### Infobox

Legen Sie den Text fest, der im Bereich der Infobox angezeigt werden soll.

Verwenden Sie Markdown, um den Text zu formatieren. Sie können auch die Infobox aus einer Markdown-Datei oder einer URL laden, indem Sie die Schaltfläche "**Aus Datei…**" oder das Feld "**URL / Laden**" verwenden – der Editor lädt den Inhalt in die Vorschau, während der Export auf die Datei oder URL verweist. Verwenden Sie "**Inline bearbeiten**", um zur direkten Bearbeitung des Textes zurückzukehren.

#### Sichtbar

Legt fest, ob die Seitenleiste sichtbar ist oder nicht

#### Informationstext

Legt den Inhalt des Infotextes fest

ℹ️ _HINWEIS: Wenn `--infobutton` verwendet wird, wird `--infotext` nicht angezeigt._
