## Schnellstart

```bash
# Einfache Benachrichtigung
dialog --title "Willkommen" \
       --message "Hallo von swiftDialog!" \
       --icon "SF=star.fill"

# Benutzereingabe-Form
dialog --title "Benutzerinformationen" \
       --message "Bitte geben Sie Ihre Daten ein:" \
       --textfield "Name,prompt=Geben Sie Ihren Namen ein" \
       --textfield "E-Mail,prompt=Geben Sie Ihre E-Mail ein" \
       --button1text "Senden"

# Fortschrittsanzeige
dialog --title "Software installieren" \
       --message "Bitte warten Sie, während wir die Dinge einrichten..." \
       --progress 10 \
       --progresstext "Installation wird gestartet..."
```
