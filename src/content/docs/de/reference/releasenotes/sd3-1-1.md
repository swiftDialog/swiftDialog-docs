## Korrekturen

- #484 - Wiederhergestellte Eigenschaft in der Hilfetext-Funktion. `name=` `--messagefont`
- #574 - Das Datums- und Zeit-Auswahlfeld ist korrekt implementiert für `--textfield`
- #608 - Wiederholbare Optionen führen nicht mehr zu einem Absturz, wenn sie als letztes Argument übergeben werden
- #630 - `--ontop` berücksichtigt die Positionierung der Anlegestellen
- #690 - Aktualisierungen der Befehlsdatei für Bildunterschriften
- #691 - Darstellung des Gruppenüberschrifts für vordefinierte Einstellungen (Preset5)
- #696 - Fehler behoben, der auftrat, wenn `--hidedefaultkeyboardaction` nicht funktionierte
- #689 - Minimieren/Maximieren im Inspektionsmodus
- Es wurden `boundedBinding` und `setIfInBounds` Hilfsfunktionen zu den Bindungen für Textfelder und Umschalter in Karten hinzugefügt, um Abstürze aufgrund von "Index außerhalb des gültigen Bereichs" zu verhindern, wenn man von Karten mit Eingabefeldern weggeht
- Um zu verhindern, dass Indexe veraltet werden, wurde von `ForEach(0..<collection.count)` zu `ForEach(Array(collection.indices), id: \.self)` umgestellt
- Fehler in `--textfield ...,date` und `--textfield ...,time` behoben, sodass die korrekten Werte zurückgegeben werden
- `--alwaysreturninput` Gibt ausgewählte, listenartige oder JSON-Ergebnisse für **alle** möglichen Beendigungswege zurück, nicht nur bei einem Klick auf eine Schaltfläche.
  - Hinweis: Skripte, die auf das alte Verhalten angewiesen sind (d.h. nur bei einem Klick auf eine Schaltfläche eine Ausgabe erzeugen), können möglicherweise neue Ergebnisse liefern. Eine Überprüfung ist möglicherweise erforderlich, wenn diese Funktion verwendet wird


## Leistungsverbesserungen

- **Remote-Abrufe:** Unterliegen expliziten Zeitüberschreitungen (10 Sekunden) für Bilder und Markdown-Inhalte
- **Bilddekodierung:** Bilder werden nur einmal dekodiert, anstatt für jeden einzelnen Render-Vorgang
- **Laden von SVG/PDF-Dateien:** Laden Sie die Dateien einmal über `.task`, anstatt sie bei jedem Rendervorgang neu zu laden
- **Anzeige von Messwerten** – Verwenden Sie `onGeometryChange` anstelle von GeometryReader
- **Timer pro Schaltfläche** – Funktionieren nur, wenn `enableOnTimer` aktiviert ist
- **JSON-Analyse:** Die Analyse von JSON-Daten erfolgt einmal beim Start, anstatt zweimal


## Verbesserungen

### JSON-Konfiguration pro Argument

Viele Argumente, die bisher nur als kommaseparierte Werte akzeptiert wurden, können jetzt als JSON-Objekte angegeben werden. Dies ermöglicht eine direktere Steuerung und ist besonders nützlich für komplexe Konfigurationen.

**Unterstützte Argumente:**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

**Beispiel:**

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

Weitere Informationen zu den detaillierten JSON-Schemas und Beispielen finden Sie in den jeweiligen Dokumentationsseiten.

### Datumsbereichsauswahl

Datum- und Zeit-Auswahlfelder unterstützen jetzt Mindest- und Höchstwerte für das Datum mithilfe der Modifikatoren `mindate=` und `maxdate=`.

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### Inspektionsmodus: Allgemeine Optionen

Der Inspektionsmodus unterstützt jetzt ein `options`-Objekt in der JSON-Konfiguration, um das allgemeine Verhalten des Dialogs zu steuern:

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## Veraltungen

- Der Modifikator `isdate` für `--textfield` wurde zugunsten von `date` und `time` als veraltet markiert
- Numerische Werte, die in JSON-Konfigurationsdateien in Anführungszeichen gesetzt sind (z. B. `"size": "40"`), lösen jetzt eine Warnung aus, die auf deren veraltete Verwendung hinweist. Verwenden Sie stattdessen Zahlen ohne Anführungszeichen
