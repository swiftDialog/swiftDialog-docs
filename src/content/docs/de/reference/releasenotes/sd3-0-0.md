## Neuerungen


### 🚨 Wichtige Änderung 🚨

swiftDialog 3.0 benötigt **macOS 15** oder eine neuere Version

Wenn Sie macOS 14 oder eine ältere Version unterstützen müssen, verwenden Sie [Version 2.5.6](https://github.com/swiftDialog/swiftDialog/releases/tag/v2.5.6)

### Neue Dokumentation

Die gesamte Dokumentation ist jetzt unter folgender Adresse verfügbar: [https://swiftdialog.app](https://swiftdialog.app/getting-started/introduction/)


### Unterstützung für das visuelle Design von macOS 26

Diese Version wird unter macOS 26 das Erscheinungsbild von macOS 26 aufweisen und unter macOS 15 das Erscheinungsbild von macOS 15

Es gibt ein neues Icon in Form eines "Squircle", das dem Branding-Stil von macOS 26 entspricht und dafür sorgt, dass es nicht in die Kategorie der "Squircle-Icons" eingeordnet wird.

Der alte, standardisierte Text für Titel und Nachricht, der bisher als "Wichtige Meldung" verwendet wurde, wurde entfernt. Wenn Titel oder Nachricht leer gelassen werden, wird eine leere Meldung und ein leerer Titel angezeigt. Das Standard-Icon verwendet nun die in der App integrierte AppIcon-Ressource anstelle eines SF-Symbols

### Neu `--inspect-mode`

Inspect Mode ist eine neue, integrierte Funktion, die eine Echtzeitüberwachung innerhalb des macOS-Dateisystems ermöglicht. Sie verfolgt den Status des Dateisystems (unter Verwendung der Apple FSEvents API) und überwacht gleichzeitig Softwareinstallationen sowie Cache-Ordner, Dateien und Plist-Inhalte, um Compliance-Prüfungen zu visualisieren. Diese Funktion ist speziell für den Einsatz während der Geräteanmeldung, der Softwarebereitstellung und der Compliance-Prüfung konzipiert

### Änderungen an `/usr/local/bin/dialog`

`/usr/local/bin/dialog` ist jetzt ein Link zu einer kompilierten `dialogcli`-Binärdatei, die in Swift geschrieben ist. Zuvor war dies ein Shell-Skript, das die Verarbeitung von Befehlszeilenargumenten und den Start des Dialog.app-Anwendungspakets übernahm.

Das integrierte `dialogcli`-Befehlszeilenprogramm ermittelt intelligent den Speicherort des `Dialog.app`-Anwendungsbündels während der Ausführung, wodurch die Dialog-App verschiebbar wird. Starten Sie die App, indem Sie `/path/to/Dialog.app/Contents/MacOS/dialogcli` ausführen

Für diese erste Version erfüllt das Programm im Wesentlichen die gleiche Funktion wie das Shell-Skript, wird aber im Laufe der Zeit erweitert. Die Unterstützung für die direkte Ausführung der `Dialog.app/Contents/MacOS/Dialog`-Datei wird in einer zukünftigen Version entfernt

⚠️ _Wichtiger Hinweis:_ In dieser Version ist die Anzahl und Reihenfolge der Argumente beim direkten Ausführen von `Dialog.app/Contents/MacOS/Dialog` entscheidend. Um die Befehle übersichtlich zu halten, geben Sie Optionen (Argumente ohne Parameter, wie z.B. `--ontop`) am _Ende_ Ihrer Befehlszeile an.

### Bauweisen

Der Modus `--builder` dient zur Unterstützung beim Erstellen von Standarddialogen und wurde mit einigen Korrekturen für fehlerhafte Funktionen sowie Aktualisierungen für einige der neuen Layouts versehen. Die Dokumentation finden Sie [hier](https://swiftdialog.app/builder/builder/)

Führen Sie das Programm `--inspect-mode` ohne Argumente aus, um das Beispiel-Konfigurationsprogramm zu starten

### Weitere Ergänzungen

 - Fügen Sie Unterstützung hinzu, um eine genaue Position auf dem Bildschirm mithilfe des Parameters --position x,y anzugeben. (#452)
 - Unterstützung für Aktionen in Listenelementen hinzufügen. Die Aktionen sind derzeit auf das Öffnen von URLs beschränkt. #472
 - Eine Option zum Eingeben des Dateipfads wurde dem Textfeld zur Dateiauswahl hinzugefügt, um den anfänglichen Dateipfad festzulegen. Wenn diese Option nicht verwendet wird, wird standardmäßig das Home-Verzeichnis des Benutzers verwendet. (#451)
 - Fügen Sie die Option "iconalpha" zur Liste der Elemente hinzu
 - Fügen Sie optional `--loghistory` für die Verwendung mit `--displaylog` #539 hinzu
 - Ein benutzerdefinierter, nichtdeterministischer linearer Fortschrittsbalken wurde hinzugefügt (dies war erforderlich, da der lineare Fortschrittsbalken von macOS 26 nicht korrekt animiert wird).
 - `--image` und `--icon` können jetzt mehrere Werte als eine durch Kommas getrennte Liste akzeptieren, z. B. `--image "/path/image1.png","/path/image2.png","/path/image3.png" #536`
 - Eine neue Option wurde zu den Auswahllisten hinzugefügt. `searchable`
   - Beispiel:
   ```
   dialog --selecttitle "Search Me",searchable --selectvalues "Apple,Banana,Cherry,Date,Elderberry,Fig,Grape,Honeydew,Kiwi,Lemon,Mango,Nectarine,Orange,Papaya,Quince,Raspberry,Strawberry,Tangerine,Ugli Fruit,Watermelon"
   ```
 - Eine Option zum Abspielen eines Sounds beim Start wurde hinzugefügt. `--sound` Akzeptiert eine Datei oder eine URL
   - Beispiel `dialog --sound /System/Library/Sounds/Glass.aiff`
   - Wenn Sie eine sehr lange Audiodatei übergeben, fügen Sie die Option `--showsoundcontrols` hinzu.
 - Unterstützung für animierte GIFs hinzugefügt (endlich).
- Ermöglichen Sie die Auswahl von Listenelementen (einzelne oder mehrere Elemente). #465
   - Neues Argument `--enablelistselect` ermöglicht die Auswahl von Listenelementen durch Anklicken. Der Auswahzustand wird als `"<title>" : "<status"` an die Standardausgabe gesendet
 - Schaltflächen können jetzt Symbole enthalten und die Textgröße ist anpassbar
   - Neue Argumente `--button1symbol` `--button2symbol` `--infobuttonsymbol`. Nimmt einen Symbolnamen als Wert entgegen. Optionale Eigenschaften: Position, Größe, Stil, Farbe. Weitere Informationen finden Sie unter `--help button1symbol`.
     - Beispiel: `--button1symbol sunrise.fill,multicolour,leading`
   - Das neue Argument `--buttontextsize` akzeptiert einen numerischen Wert, um die gewünschte Textgröße festzulegen
   - Die Textwerte für Schaltflächen können jetzt als `nil` angegeben werden, um die Anzeige von Text auf der Schaltfläche zu deaktivieren
 - Aktivieren Sie die Verwendung von Schaltfläche 1 mit gestapeltem Layout und Timer #520
 - Das swiftDialog-Icon kann mit `--showdockicon` im Dock angezeigt werden
   - Das Icon für die Dock-Leiste kann mit einem benutzerdefinierten Bild versehen werden, und zwar mit `--dockicon <img>`
   - Das Icon in der Dock-Leiste kann ein kleines Icon (Badge) enthalten, das `--dockbadge <text>`
   - Die Sichtbarkeit von Icons und das zugehörige Badge können über eine Konfigurationsdatei aktualisiert werden
   - Das Icon im Dock kann dazu gebracht werden, zu hüpfen: Im normalen Modus ein Hüpfen, im kritischen Modus mehrere Hüpfer
 - Die Übergänge zwischen SF-Symbolen werden jetzt animiert, wenn es sich um kompatible Symboltypen handelt
 - Hinzugefügte Option `--hideotherapps`: Diese Option bewirkt, dass alle anderen Anwendungen ausgeblendet werden, wenn swiftDialog gestartet wird
 - Hinzugefügte Unterstützung für Textfarben innerhalb des Textes unter Verwendung des `:colour[text]`-Formats. Zum Beispiel: `"Text can be :blue[blue] or :red[red]"`
   - Unterstützt in jedem Textbereich, der Markdown verwendet, sowie in `--title` und `--bannertitle`
 - Hinzugefügte Unterstützung für die linke/rechte Textausrichtung für Titel und Fortschrittsanzeige
   - `--titlefont alignment=left`
   - `--progresstextalignment left`
