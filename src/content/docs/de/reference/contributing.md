# Beitragen

Beiträge sind herzlich willkommen! Es gibt viele Möglichkeiten, dieses Projekt zu unterstützen, sei es durch Code, Feedback oder finanzielle Unterstützung.

## Code-Beiträge

Wenn Sie Code beitragen möchten, forken Sie bitte das Repository, erstellen Sie einen neuen Zweig und reichen Sie einen Pull Request ein.

Bei der Einreichung von Pull Requests bitten wir Sie, sich möglichst an die bestehende Code-Struktur zu halten, um interne Konsistenz zu gewährleisten. Ich lege großen Wert darauf, dass der Code kompilierbar ist, aber ich erwarte nicht unbedingt eine perfekte Formatierung. Sollte der Code jedoch besonders unübersichtlich sein, kann ich Sie bitten, ihn zu überarbeiten.

## Probleme melden

- **Funktionswünsche:** Wenn Sie eine Idee für eine neue Funktion haben, diese aber selbst nicht umsetzen können, senden Sie bitte eine Anfrage und ich werde sie in die Liste der geplanten Aufgaben aufnehmen.
- **Fehlerberichte:** Wenn Sie einen Fehler entdecken, melden Sie ihn bitte als Problemfall und beschreiben Sie dabei, wie man das Problem reproduzieren kann.

[Hier klicken, um einen neuen Fehlerbericht zu erstellen oder ein Problem zu melden.](https://github.com/swiftDialog/swiftDialog/issues/new/choose)

## Finanzielle Beiträge

Wenn Sie dieses Projekt nützlich finden – insbesondere wenn es Ihre Arbeit oder Ihr Unternehmen unterstützt –, bitten wir Sie, eine finanzielle Unterstützung in Betracht zu ziehen. Ihre Unterstützung trägt zur kontinuierlichen Weiterentwicklung und Wartung bei.

## Ein Hinweis zur Freundlichkeit

Dies ist ein Projekt, an dem ich in meiner Freizeit arbeite. Wenn Sie Verbesserungsvorschläge haben oder eine bessere Vorgehensweise für etwas kennen, würde ich mich sehr freuen, davon zu hören – sei es als Pull Request, als Fehlerbericht oder einfach als Kommentar. Ich bitte lediglich darum, dass das Feedback konstruktiv und respektvoll ist.
