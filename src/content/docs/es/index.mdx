## Ejemplo de inicio rápido

```bash
# Notificación simple
dialog --title "Bienvenido" \
       --message "Hola desde swiftDialog!" \
       --icon "SF=star.fill"

# Formulario de información del usuario
dialog --title "Información del usuario" \
       --message "Ingrese sus datos:" \
       --textfield "Nombre,prompt=Ingrese su nombre" \
       --textfield "Correo electrónico,prompt=Ingrese su correo electrónico" \
       --button1text "Enviar"

# Indicador de progreso
dialog --title "Instalando software" \
       --message "Espere mientras configuramos todo..." \
       --progress 10 \
       --progresstext "Iniciando la instalación..."
```
