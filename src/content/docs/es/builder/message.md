### Propiedades

Las siguientes propiedades se pueden configurar. Haga clic en el botón "Restablecer" para volver a los valores predeterminados

#### Alineación del texto

Alinea el texto a la izquierda, al centro o a la derecha

#### Posición vertical

Cuando está activada, la posición vertical se establece en el centro en lugar de en la parte superior

#### Color

Establece el color del mensaje

#### Código fuente en Markdown

Además de escribir el mensaje directamente, puede cargarlo desde un archivo Markdown o una URL utilizando el botón "**Desde archivo…**" o el campo "**URL / Cargar**". El editor carga el contenido en la vista previa, mientras que el archivo JSON / comando exportado hace referencia al archivo o a la URL (para que se cargue en tiempo de ejecución). Utilice "**Editar en línea**" para volver a editar el texto directamente.

ℹ️ _NOTA: No se pueden realizar ajustes en la fuente._
