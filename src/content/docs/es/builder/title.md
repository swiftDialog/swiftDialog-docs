## Título

Estas opciones le permiten modificar el título y la barra de título

<img width="500" alt="image" src="/builder/builder_title.png" />

Las siguientes opciones de configuración están disponibles:

#### Título del texto

Establece el texto que se mostrará en la barra de título

ℹ️ _Establecer en `none` para ocultar completamente el área del título._

#### Color de la fuente

Al hacer clic en el selector de color, se abrirá el selector de colores de macOS. Esto establecerá el color del texto del título al color deseado, y este color se representará en el resultado como un valor hexadecimal

#### Tamaño de fuente

Utilice el control deslizante para cambiar el tamaño de fuente deseado.

El control deslizante mostrará valores entre 10 y 80, pero se pueden introducir valores mayores o menores manualmente.


## Título (en un banner)

Aquí también se configuran las imágenes y las propiedades de los banners

#### Imagen del banner

Arrastra una imagen sobre la representación del banner para establecer la imagen, o haz clic en el botón "Seleccionar" para abrir una ventana de selección de archivos

#### Banner habilitado

Permite o desactiva la imagen de encabezado

#### Título del banner

Permite mostrar `--title` texto sobre la imagen de fondo

#### Sombra de texto

Cuando se utiliza con `--bannertitle`, permitirá aplicar una sombra que diferenciará el texto de la imagen de fondo

#### Altura del banner

Utilice el control deslizante para ajustar la altura del área de la imagen del banner
