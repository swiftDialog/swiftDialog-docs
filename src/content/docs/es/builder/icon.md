## Propiedades

#### Icono

Para establecer el icono, arrastre una imagen o una aplicación y suéltela sobre el icono representado en la ventana del constructor

<img width="200" alt="image" src="/builder/builder_icon_drag.png" />

<img width="500" alt="image" src="/builder/builder_icon_drop.png" />

También puede utilizar el botón "Seleccionar" para abrir un cuadro de diálogo de selección de archivos, o escribir el nombre de un símbolo de SF en el formato `sf=name` en el cuadro de texto del valor del icono (donde `name` es el nombre de un símbolo de SF válido).

Alternativamente, haga clic en el icono de vista previa para abrir la ventana emergente de símbolos SF y configure el nombre y el color de un símbolo SF; se utiliza el mismo selector que para [los elementos de la lista](/es/builder/listitems/) y las [casillas de verificación](/es/builder/checkboxes/). El icono de superposición utiliza el mismo selector.

#### Visible

Establece si el icono es visible o no

#### Centrado

Mueve el icono desde el área de la barra lateral izquierda a una posición central, ubicada encima del área `--message`

#### Tamaño del icono

Establezca el tamaño del icono en puntos

ℹ️ _NOTA: Si el tamaño establecido no cabe en el espacio disponible, el icono se ajustará al tamaño máximo que sí quepa._

#### Icono Alpha

Establezca el valor de transparencia del icono. 0 = transparente, 1 = opaco

#### Superposición

Establecer la superposición del icono

ℹ️ _NOTA: La función de superposición no está disponible cuando se utiliza un icono en modo centrado._
