Establezca las propiedades de la barra lateral del diálogo

<img width="500" alt="image" src="/builder/builder_sidebar.png" />

## Propiedades

#### Cuadro de información

Establezca el texto que se mostrará en el área del cuadro de información.

Utilice Markdown para dar formato al contenido de texto. También puede cargar la información de la caja de información desde un archivo Markdown o una URL utilizando el botón "**Desde archivo…**" o el campo "**URL / Cargar**". El editor carga el contenido en la vista previa, mientras que la exportación hace referencia al archivo o la URL. Utilice "**Editar en línea**" para volver a editar el texto directamente.

#### Visible

Establece si la barra lateral es visible o no

#### Texto informativo

Establece el contenido del texto informativo

ℹ️ _NOTA: Cuando se utiliza `--infobutton`, `--infotext` no se mostrará._
