Agregue uno o más elementos de tipo casilla de verificación al cuadro de diálogo

<img width="500" alt="image" src="/builder/builder_checkbox.png" />

Haga clic en el botón `[+]` para agregar una nueva entrada a la lista de elementos de casilla de verificación

Haga clic en el icono de la papelera para eliminar una opción de casilla de verificación

Arrastre el control (☰) que se encuentra a la izquierda de una fila para cambiar el orden de las entradas


<img width="500" alt="image" src="/builder/builder_checkbox_populated.png" />

## Propiedades

#### Formato de salida

Especificar si la salida del diálogo debe estar en formato JSON o no

#### Botón de ayuda

Haga clic para ver la descripción de ayuda `--checkbox`

#### Mostrar

Permite mostrar u ocultar la casilla de verificación

#### Estilo de interruptor

Permite usar el estilo de interruptor. Si no se selecciona, se utiliza el estilo de casilla de verificación

#### Icono

_Solo disponible cuando se activa el estilo `switch`._

Arrastra una imagen o un paquete de aplicaciones sobre la vista previa del icono para establecer el valor del icono

Haga clic en el área de vista previa del icono para establecer un símbolo y un color de SF

#### Etiqueta

Establezca el texto de la etiqueta del cuadro de verificación

#### Nombre

Establezca el valor del nombre para la casilla de verificación. Cuando se utiliza, la propiedad `name` se mostrará en la salida para identificar la casilla de verificación en lugar de la etiqueta

#### Verificado

Establece el estado inicial de la casilla de verificación

#### Discapacitado/a

Establece el estado de "deshabilitado" de la casilla de verificación
