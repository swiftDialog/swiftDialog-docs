### Video

Haga clic en "Seleccionar" para abrir un cuadro de diálogo de selección de archivos

Seleccione "Activar" para mostrar el área de visualización de video

Seleccione "Reproducción automática" para establecer el valor de reproducción automática

### Web

Utilice el interruptor para activar o desactivar la visualización del contenido web

Introduzca la URL deseada para mostrarla
