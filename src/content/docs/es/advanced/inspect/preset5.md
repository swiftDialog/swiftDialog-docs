Portal de autoservicio preconfigurado: Vista web personalizada con autenticación opcional

Soportes:
- Pantallas de introducción y cierre opcionales, creadas con SwiftUI, para personalizar el proceso de configuración y adaptarlo a la imagen de marca
- URLs sencillas y sin autenticación (por ejemplo, SOFA, documentación).
- Portales autenticados con inyección de tokens
- Tematización para múltiples marcas a través de la configuración de aplicaciones MDM

Flujo: Pantallas de introducción (opcional) → Vista web del portal → Pantallas de cierre (opcional).
