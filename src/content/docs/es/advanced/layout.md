## Orden de visualización personalizada

`--vieworder <csv>`

Con la excepción de las imágenes y el contenido de los mensajes, los elementos de la ventana pueden ser reorganizados.

El orden predeterminado es el siguiente:
 > Archivo de texto
 > Contenido web
 > elemento de lista
 > casilla de verificación
 > campo de texto
 > botón de opción
 > lista desplegable

 Estos elementos se pueden reorganizar para adaptarse a las necesidades de visualización, especificando el orden deseado como una lista CSV de elementos, por ejemplo: `--vieworder "dropdown, textfield, checkbox"`
