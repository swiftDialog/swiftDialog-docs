# Contribuyendo

¡Las contribuciones son más que bienvenidas! Existen muchas formas de apoyar este proyecto, ya sea a través de código, comentarios o apoyo financiero.

## Contribuciones de código

Si desea contribuir con código, por favor, clone el repositorio, cree una rama y envíe una solicitud de incorporación.

Al enviar solicitudes de incorporación de cambios, por favor, intenten seguir la estructura de código existente para mantener la coherencia interna. No soy especialmente estricto con el formato, siempre y cuando el código se compile correctamente, aunque es posible que les pida que lo organicen si está especialmente desordenado.

## Informar de problemas

- **Sugerencias de funciones:** Si tiene una idea para una nueva función, pero no puede implementarla usted mismo, por favor, registre un problema (issue) y lo añadiré a la lista de tareas pendientes.
- **Informes de errores:** Si encuentra un error, por favor repórtelo como un problema, incluyendo una descripción de cómo reproducir el error.

[Haga clic aquí para crear un nuevo formulario o para informar de un problema.](https://github.com/swiftDialog/swiftDialog/issues/new/choose)

## Contribuciones financieras

Si considera que este proyecto es útil, especialmente si le ayuda en su trabajo o negocio, le pedimos que considere la posibilidad de contribuir económicamente. Su apoyo contribuye al desarrollo y mantenimiento continuos del proyecto.

- [GitHub Sponsors](https://github.com/sponsors/bartreardon)
- [Invítame a tomar un café.](https://www.buymeacoffee.com/bartreardon)

Las organizaciones que utilizan este proyecto con fines comerciales pueden patrocinarlo si consideran que aporta valor. No existe ninguna obligación, y esto no afectará a mi relación con nadie, pero sí contribuye a mantener el proyecto en marcha.

## Una reflexión sobre la amabilidad

Este es un proyecto personal que mantengo en mi tiempo libre. Si tienen alguna sugerencia de mejora o conocen una mejor manera de hacer algo, me encantaría saberlo, ya sea a través de una solicitud de cambio, un informe de problema o simplemente un comentario. Lo único que pido es que los comentarios sean constructivos y respetuosos.
