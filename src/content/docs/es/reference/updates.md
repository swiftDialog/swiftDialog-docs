Dialog no cuenta con una función de actualización integrada.

Para mantener el diálogo actualizado, existen varias opciones

## Archivo de instalación PKG o archivo ZIP.

El método más sencillo es descargar el archivo PKG o ZIP desde la [página de lanzamientos](https://github.com/bartreardon/Dialog-public/releases)] manualmente e instalarlo directamente, o importarlo en la herramienta de gestión que prefieras.

## Installomator

La versión 0.7 de [Installomator](https://github.com/Installomator/Installomator) incluye una etiqueta para el cuadro de diálogo.

Para instalar dialog utilizando Installomator, simplemente descargue y ejecute `./Installomator.sh dialog`, o importe el script de Installomator en la herramienta de gestión que prefiera.
