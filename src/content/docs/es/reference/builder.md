## Kit de construcción swiftDialog (versión alfa).

swiftDialog incluye un nuevo comando `--builder`. Cuando se invoca, se muestra una ventana adicional que permite actualizar el contenido y las propiedades del diálogo, y ver los resultados en tiempo real.

Luego, puede generar un archivo JSON que se puede utilizar para recrear el diálogo tal como lo diseñó

** NOTA: Esta función aún no está completamente desarrollada y algunas opciones de configuración no están disponibles o no aparecerán en el archivo JSON generado. El desarrollo está en curso. **
