## ¿Qué hay de nuevo?


### 🚨 Cambio importante 🚨

swiftDialog 3.0 requiere **macOS 15** o una versión más reciente

Si necesita compatibilidad con macOS 14 o versiones anteriores, utilice [la versión 2.5.6](https://github.com/swiftDialog/swiftDialog/releases/tag/v2.5.6)

### Nueva documentación

Toda la documentación se encuentra ahora disponible en [https://swiftdialog.app](https://swiftdialog.app/getting-started/introduction/)


### Soporte para el estilo visual de macOS 26

Esta versión tendrá la apariencia de macOS 26 cuando se ejecute en macOS 26, y la apariencia de macOS 15 cuando se ejecute en macOS 15

Existe un nuevo icono con forma de "cuadrado redondeado" que se adapta al estilo de marca de macOS 26 y evita que se utilice una forma incorrecta.

Se ha eliminado el texto predefinido anterior de "Mensaje importante" para el título y el mensaje. Si se deja en blanco el título o el mensaje, se generará un mensaje y un título vacíos. El icono predeterminado utiliza el recurso AppIcon integrado en lugar de un símbolo de SF

### Nuevo `--inspect-mode`

El modo "Inspección" es una nueva función integrada que permite el monitoreo en tiempo real dentro del sistema de archivos de macOS. Realiza un seguimiento del estado del sistema de archivos (utilizando la API FSEvents de Apple) mientras supervisa la instalación de aplicaciones y examina carpetas, archivos y el contenido de archivos plist para visualizar las comprobaciones de cumplimiento. Esta función está diseñada específicamente para su uso durante el registro de dispositivos, la implementación de software y las auditorías de cumplimiento

### Cambios a `/usr/local/bin/dialog`

`/usr/local/bin/dialog` ahora es un enlace a un archivo binario compilado `dialogcli` escrito en Swift. Anteriormente, esto era un script de shell que se encargaba del procesamiento de comandos y del lanzamiento del paquete de la aplicación Dialog.app.

La utilidad de línea de comandos integrada `dialogcli` determina de forma inteligente la ubicación del paquete de la aplicación `Dialog.app` al ejecutarse, lo que permite que la aplicación Dialog sea trasladable. Para ejecutarla, utilice el comando `/path/to/Dialog.app/Contents/MacOS/dialogcli`

Para esta versión inicial, esta funcionalidad generalmente realiza la misma tarea que el script de shell, pero se ampliará con el tiempo. El soporte para ejecutar el archivo binario `Dialog.app/Contents/MacOS/Dialog` directamente se eliminará en una futura versión

⚠️ _Nota importante:_ En esta versión, al ejecutar `Dialog.app/Contents/MacOS/Dialog` directamente, el número y el orden de los argumentos son importantes. Para mayor claridad, especifique las opciones (argumentos sin parámetro, como `--ontop`) al *final* de su comando.

### Modos de construcción

El modo `--builder` está diseñado para ayudar en la creación de diálogos estándar y ha sido actualizado con algunas correcciones para solucionar problemas de funcionamiento y con mejoras en algunos de los nuevos diseños. La documentación se encuentra [aquí](https://swiftdialog.app/builder/builder/)

Ejecute el programa `--inspect-mode` sin argumentos para abrir la utilidad de configuración de ejemplo

### Otras adiciones

 - Añade la opción de especificar una ubicación exacta en la pantalla utilizando el parámetro --position x,y. (Referencia: #452)
 - Añadir soporte para acciones en los elementos de la lista. Las acciones están limitadas a la apertura de URLs. #472
 - Se ha añadido una opción para especificar la ruta del archivo al campo de texto para la selección de archivos, lo que permite establecer la ruta inicial del archivo. Por defecto, si no se especifica, se utiliza el directorio de inicio del usuario. #451
 - Añadir la opción "iconalpha" a la lista de elementos
 - Añadir opcionalmente `--loghistory` para su uso con `--displaylog` #539
 - Se agregó una barra de progreso lineal personalizada que indica un estado indeterminado (esto era necesario porque la barra de progreso lineal de macOS 26 no se anima correctamente).
 - `--image` y `--icon` ahora pueden aceptar múltiples valores como una única lista separada por comas, por ejemplo: `--image "/path/image1.png","/path/image2.png","/path/image3.png" #536`
 - Se ha añadido `searchable` una opción a las listas desplegables
   - ejemplo:
   ```
   dialog --selecttitle "Search Me",searchable --selectvalues "Apple,Banana,Cherry,Date,Elderberry,Fig,Grape,Honeydew,Kiwi,Lemon,Mango,Nectarine,Orange,Papaya,Quince,Raspberry,Strawberry,Tangerine,Ugli Fruit,Watermelon"
   ```
 - Se ha añadido `--sound` para reproducir un sonido al iniciar la aplicación. Acepta un archivo o una URL
   - ejemplo `dialog --sound /System/Library/Sounds/Glass.aiff`
   - Si introduce un archivo de audio muy extenso, añada la opción `--showsoundcontrols`.
 - Se ha añadido soporte para imágenes GIF animadas (por fin).
- Permitir que los elementos de la lista sean seleccionables (uno o varios). #465
   - Nuevo argumento `--enablelistselect`: permite seleccionar elementos de la lista al hacer clic. El estado de la selección se envía a la salida estándar (stdout) como `"<title>" : "<status"`
 - Ahora, los botones pueden incluir símbolos y el tamaño del texto es ajustable
   - Nuevos argumentos `--button1symbol` `--button2symbol` `--infobuttonsymbol`. Acepta el nombre de un símbolo SF como valor. Propiedades opcionales: posición, tamaño, estilo, color. Consulte `--help button1symbol` para obtener más información.
     - Ejemplo: `--button1symbol sunrise.fill,multicolour,leading`
   - El nuevo argumento `--buttontextsize` acepta un valor numérico para establecer el tamaño de texto deseado
   - Los valores del texto de los botones ahora se pueden especificar como `nil` para desactivar la visualización del texto del botón
 - Habilitar el uso del botón 1 con estilo apilado y el temporizador número 520
 - El icono de swiftDialog se puede mostrar en el Dock utilizando `--showdockicon`
   - El icono de la barra de tareas se puede configurar para mostrar una imagen personalizada utilizando `--dockicon <img>`
   - El icono de la barra de tareas puede mostrar un distintivo o indicador. `--dockbadge <text>`
   - La visibilidad del icono y el distintivo pueden actualizarse a través de un archivo de comandos
   - El icono del dock puede hacer que el icono rebote: en el modo normal, un solo rebote; en el modo crítico, múltiples rebotes
 - Las transiciones de los símbolos de SF ahora se animan entre tipos de símbolos compatibles
 - Se ha añadido una opción `--hideotherapps`: esta opción hará que todas las demás aplicaciones se oculten cuando se inicie swiftDialog
 - Se agregó soporte para el color del texto dentro del texto, utilizando el formato `:colour[text]`. Por ejemplo: `"Text can be :blue[blue] or :red[red]"`
   - Compatible con cualquier área de texto en formato Markdown, así como con `--title` y `--bannertitle`
 - Se ha añadido soporte para la alineación de texto a la izquierda o a la derecha para el título y el texto de la barra de progreso
   - `--titlefont alignment=left`
   - `--progresstextalignment left`
