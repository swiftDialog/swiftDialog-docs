## Correcciones

- #484 - Propiedad restaurada `name=` en el texto de ayuda `--messagefont`
- #574 - El selector de fecha y hora se ha configurado correctamente para `--textfield`
- #608 - Las opciones repetibles ya no provocan fallos cuando se utilizan como último argumento
- #630 - `--ontop` Respeta la ubicación del muelle
- #690 - Actualizaciones del archivo de comandos para la función de subtítulos de imágenes
- #691 - Renderización del encabezado del grupo "Preset5"
- #696 - Se corrigió un error que ocurría cuando `--hidedefaultkeyboardaction` no funcionaba
- #689 - Minimizar/maximizar en modo de inspección
- Se agregaron `boundedBinding` y `setIfInBounds` funciones de utilidad a las vinculaciones de texto y conmutadores en los campos de la tarjeta para evitar fallos de "Índice fuera de rango" al pasar a otras tarjetas que contienen campos de entrada
- Se cambió de `ForEach(0..<collection.count)` a `ForEach(Array(collection.indices), id: \.self)` para evitar problemas relacionados con índices obsoletos
- Se corrigieron `--textfield ...,date` y `--textfield ...,time` para que devuelvan los valores de forma correcta
- `--alwaysreturninput` Devuelve resultados seleccionados, listados o en formato JSON en **todos** los caminos de salida, no solo al presionar un botón.
  - Nota: Los scripts que dependen del comportamiento anterior (que solo se activan al pulsar un botón) podrían mostrar resultados diferentes. Es posible que sea necesario revisar el funcionamiento si se utiliza esta función


## Mejoras en el rendimiento

- **Descargas remotas:** Limitadas por tiempos de espera explícitos (10 segundos) para imágenes y contenido en formato Markdown
- **Decodificación de imágenes:** Las imágenes se decodifican una sola vez, en lugar de por cada renderizado
- **Carga de archivos SVG/PDF:** Cargar una sola vez a través de `.task`, en lugar de cargar por cada renderizado
- **Visualización de medidas** - Utilice `onGeometryChange` en lugar de GeometryReader
- **Temporizadores por botón** - Solo se activan cuando `enableOnTimer` está configurado
- **Análisis de JSON:** Se realiza el análisis una sola vez al inicio, en lugar de dos veces


## Mejoras

### Configuración JSON para argumentos individuales

Muchos argumentos que anteriormente solo aceptaban valores separados por comas ahora pueden especificarse como objetos JSON. Esto proporciona un control más preciso y es especialmente útil para configuraciones complejas.

**Argumentos respaldados:**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

**Ejemplo:**

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

Consulte las páginas de documentación individuales para obtener información detallada sobre los esquemas JSON y ejemplos.

### Rangos de fechas seleccionables

Los selectores de fecha y hora ahora admiten límites mínimos y máximos de fecha a través de los modificadores `mindate=` y `maxdate=`.

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### Opciones generales del modo de inspección

El modo de inspección ahora admite un objeto `options` en la configuración JSON para controlar el comportamiento general del diálogo:

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## Obsolescencias

- El modificador `isdate` para `--textfield` ha quedado obsoleto y ha sido reemplazado por `date` y `time`
- Los valores numéricos que aparecen entre comillas en la configuración JSON (por ejemplo, `"size": "40"`) ahora generan una advertencia de obsolescencia. Utilice números sin comillas en su lugar
