## Kit de développement swiftDialog (version alpha).

swiftDialog comprend une nouvelle `--builder` commande. Lorsqu'elle est appelée, une fenêtre supplémentaire s'affiche, vous permettant de mettre à jour le contenu et les propriétés de la boîte de dialogue, et de visualiser les résultats en temps réel.

Vous pouvez ensuite générer un fichier JSON qui peut être utilisé pour recréer le dialogue selon vos spécifications

** REMARQUE : Cette fonctionnalité n'est pas encore entièrement finalisée, et certains paramètres ne sont pas disponibles ou ne seront pas présents dans le fichier JSON généré. Le développement est en cours. **
