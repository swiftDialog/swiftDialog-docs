## Corrections

- #484 - Propriété restaurée `name=` dans le texte d'aide `--messagefont`
- #574 - Le sélecteur de date et d'heure a été correctement configuré pour `--textfield`
- #608 - Les options répétables ne provoquent plus de plantage lorsqu'elles sont utilisées comme argument final
- #630 - `--ontop` Prend en compte la position des quais
- #690 - Mises à jour du fichier de commandes pour la légende des images
- #691 - Rendu de l'en-tête du groupe "Preset5"
- #696 - Correction d'une erreur qui empêchait le bon fonctionnement de `--hidedefaultkeyboardaction`
- #689 - Minimiser/maximiser en mode inspection
- Ajout de fonctionnalités auxiliaires `boundedBinding` et `setIfInBounds` aux liaisons de champs de texte et de bascules dans les cartes, afin d'éviter les erreurs de type "Index hors limites" lors du passage à d'autres cartes contenant des champs de saisie
- Passage de `ForEach(0..<collection.count)` à `ForEach(Array(collection.indices), id: \.self)` pour éviter les problèmes liés aux index obsolètes
- Corrigé `--textfield ...,date` et `--textfield ...,time` pour que les valeurs soient renvoyées correctement
- `--alwaysreturninput` renvoie les résultats sélectionnés, la liste ou le format JSON sur **tous** les chemins de sortie, et non pas seulement lorsqu'on appuie sur un bouton.
  - Remarque : Les scripts qui reposent sur le comportement précédent (qui ne renvoie de résultat qu'à la pression d'un bouton) pourraient afficher de nouveaux résultats. Une vérification peut être nécessaire si vous utilisez cette fonctionnalité


## Améliorations des performances

- **Téléchargements à distance :** Les délais d'attente sont limités explicitement (10 secondes) pour les images et le format Markdown
- **Décodage des images** : Les images sont décodées une seule fois, au lieu de le faire pour chaque rendu
- **Chargement des fichiers SVG/PDF** : Charger une seule fois via `.task`, au lieu de le faire pour chaque rendu
- **Afficher les mesures** - Utilisez `onGeometryChange` au lieu de GeometryReader
- **Minuteries par bouton** - Ne fonctionnent que lorsque `enableOnTimer` est activé
- **Analyse du format JSON** : Le format JSON est analysé une seule fois au démarrage, au lieu de deux fois


## Améliorations

### Configuration JSON par argument

De nombreux paramètres qui, auparavant, ne pouvaient être spécifiés qu'avec des valeurs séparées par des virgules, peuvent désormais être définis sous forme d'objets JSON. Cela offre un contrôle plus précis et est particulièrement utile pour les configurations complexes.

**Arguments pris en charge :**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

Veuillez me fournir le texte que vous souhaitez que je traduise

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

Consultez les pages de documentation individuelles pour obtenir les schémas JSON détaillés et des exemples.

### Limites du sélecteur de date

Les sélecteurs de date et d'heure prennent désormais en charge les limites de date minimales et maximales grâce aux modificateurs `mindate=` et `maxdate=`.

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### Mode d'inspection : Options générales

Le mode inspection prend désormais en charge un objet `options` dans la configuration JSON pour contrôler le comportement général de la boîte de dialogue.

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## Obsolète

- Le modificateur `isdate` pour `--textfield` a été déprécié au profit de `date` et `time`
- Les valeurs numériques entre guillemets dans la configuration JSON (par exemple, `"size": "40"`) déclenchent désormais un avertissement de dépréciation. Utilisez plutôt des nombres sans guillemets
