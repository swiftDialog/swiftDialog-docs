Il n'y en a pas.

Dialog a été conçu pour être aussi simple que possible. Tout ce qui peut être configuré l'est par le biais d'options en ligne de commande, qui constituent la méthode principale d'interaction.

Il n'y a aucune logique autre que celle nécessaire pour afficher la boîte de dialogue.

L'objectif est que vous, en tant qu'administrateur déployant cet outil, puissiez écrire le code nécessaire pour appeler cet outil et traiter les résultats, en utilisant le langage de script de votre choix.
