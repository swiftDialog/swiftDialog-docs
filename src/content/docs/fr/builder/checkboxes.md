Ajoutez un ou plusieurs éléments de type case à cocher à la boîte de dialogue

<img width="500" alt="image" src="/builder/builder_checkbox.png" />

Cliquez sur le bouton `[+]` pour ajouter une nouvelle entrée à la liste des éléments à cocher

Cliquez sur l'icône de la corbeille pour supprimer une case à cocher

Faites glisser la poignée (☰) située à gauche de chaque ligne pour modifier l'ordre des éléments


<img width="500" alt="image" src="/builder/builder_checkbox_populated.png" />

## Propriétés

#### Format de sortie

Définir si la sortie de la boîte de dialogue utilise ou non le format JSON

#### Bouton d'aide

Cliquez pour afficher la description d'aide. `--checkbox`

#### Afficher

Permet d'activer ou de désactiver l'affichage de la case à cocher

#### Style interrupteur

Permet de définir le style "interrupteur". Si cette option n'est pas sélectionnée, le style "case à cocher" est utilisé

#### Icône

_Uniquement disponible lorsque le style `switch` est activé._

Faites glisser une image ou un ensemble d'applications sur l'aperçu de l'icône pour définir la valeur de cette icône

Cliquez sur la zone de prévisualisation de l'icône pour définir le symbole et la couleur de l'objet SF

#### Étiquette

Définir le texte de l'étiquette de la case à cocher

#### Nom

Définissez la valeur du nom pour la case à cocher. Lorsque cette propriété est utilisée, elle sera affichée dans la sortie pour identifier la case à cocher au lieu de l'étiquette. `name`

#### Vérifié

Définit l'état initial de la case à cocher

#### Handicapé(e)s

Définit l'état "désactivé" de la case à cocher
