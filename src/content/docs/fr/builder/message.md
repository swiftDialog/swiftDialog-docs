### Propriétés

Les propriétés suivantes peuvent être modifiées. Cliquez sur le bouton "Réinitialiser" pour rétablir ces paramètres par défaut

#### Alignement du texte

Positionne le texte à gauche, au centre ou à droite

#### Position verticale

Lorsque cette option est activée, la position verticale est définie comme étant centrée au lieu d'être alignée en haut

#### Couleur

Définit la couleur du message

#### Source Markdown

En plus de taper le message directement, vous pouvez le charger à partir d'un fichier Markdown ou d'une URL en utilisant le bouton **À partir du fichier…** ou le champ **URL / Charger**. L'outil de création affiche le contenu dans l'aperçu, tandis que le fichier JSON/la commande exportée fait référence au fichier ou à l'URL (ce qui permet de le charger au moment de l'exécution). Utilisez **Modifier en ligne** pour revenir à la modification du texte directement.

ℹ️ _NOTE : Les ajustements de police ne sont pas disponibles._
