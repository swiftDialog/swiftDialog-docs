## Propriétés

#### Icône

Pour définir l'icône, faites glisser une image ou une application vers la représentation de l'icône dans la fenêtre de création

<img width="200" alt="image" src="/builder/builder_icon_drag.png" />

<img width="500" alt="image" src="/builder/builder_icon_drop.png" />

Vous pouvez également utiliser le bouton "Sélectionner" pour ouvrir une boîte de dialogue de sélection de fichier, ou saisir le nom d'un symbole SF dans le format `sf=name` dans le champ de texte "Valeur de l'icône" (où `name` est le nom d'un symbole SF valide).

Alternativement, cliquez sur l'icône de prévisualisation pour ouvrir la fenêtre contextuelle des symboles SF et définir un nom et une couleur pour le symbole SF. Le même sélecteur est utilisé pour les [éléments de liste](/fr/builder/listitems/) et les [cases à cocher](/fr/builder/checkboxes/). L'icône de superposition utilise également ce même sélecteur.

#### Visible

Détermine si l'icône est visible ou non

#### Centré

Répositionne l'icône, qui se trouvait dans la barre latérale gauche, pour la placer au centre, au-dessus de la zone `--message`

#### Taille de l'icône

Définissez la taille de l'icône en points

ℹ️ _NOTE : Si la taille définie ne peut pas être affichée dans l'espace disponible, l'icône sera réduite à la taille maximale qui peut y entrer._

#### Icône Alpha

Définir le niveau de transparence de l'icône. 0 = transparent, 1 = opaque

#### Superposition

Définir la superposition de l'icône

ℹ️ _REMARQUE : La superposition n'est pas disponible lorsque vous utilisez une icône en mode centré._
