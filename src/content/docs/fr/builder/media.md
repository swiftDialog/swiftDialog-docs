### Vidéo

Cliquez sur "Sélectionner" pour ouvrir une fenêtre de sélection de fichier

Sélectionnez "Activer" pour afficher la zone de visualisation vidéo

Sélectionnez "Lecture automatique" pour définir la valeur de lecture automatique

### Web

Utilisez le bouton pour activer ou désactiver l'affichage du contenu web

Entrez l'URL souhaité pour afficher le contenu
