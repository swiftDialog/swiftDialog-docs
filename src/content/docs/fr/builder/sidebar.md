Définir les propriétés de la barre latérale de dialogue

<img width="500" alt="image" src="/builder/builder_sidebar.png" />

## Propriétés

#### Boîte d'informations

Définissez le texte qui doit s'afficher dans la zone de l'info-boîte.

Utilisez le format Markdown pour mettre en forme le contenu textuel. Vous pouvez également charger la boîte d'informations à partir d'un fichier Markdown ou d'une URL en utilisant le bouton **À partir du fichier…** ou le champ **URL / Charger** ; l'outil affiche le contenu dans l'aperçu, tandis que l'exportation fait référence au fichier ou à l'URL. Utilisez la fonction **Modifier en ligne** pour revenir à la modification directe du texte.

#### Visible

Définit si la barre latérale est visible ou non

#### Texte informatif

Définit le contenu du texte d'information

ℹ️ _NOTE : Lorsque `--infobutton` est utilisé, `--infotext` ne sera pas affiché._
