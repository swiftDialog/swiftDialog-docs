## Exemple de démarrage rapide

```bash
# Notification simple
dialog --title "Bienvenue" \
       --message "Bonjour depuis swiftDialog !" \
       --icon "SF=star.fill"

# Formulaire de saisie utilisateur
dialog --title "Informations utilisateur" \
       --message "Veuillez saisir vos coordonnées :" \
       --textfield "Nom,prompt=Entrez votre nom" \
       --textfield "E-mail,prompt=Entrez votre e-mail" \
       --button1text "Soumettre"

# Indicateur de progression
dialog --title "Installation du logiciel" \
       --message "Veuillez patienter pendant l'installation..." \
       --progress 10 \
       --progresstext "L'installation démarre..."
```
