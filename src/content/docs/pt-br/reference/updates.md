O sistema Dialog não possui uma função de atualização integrada.

Para manter as caixas de diálogo atualizadas, existem diversas opções disponíveis

## Arquivo de instalação (PKG) ou arquivo compactado (ZIP).

O método mais simples é baixar o arquivo PKG ou ZIP da [página de lançamentos](https://github.com/bartreardon/Dialog-public/releases)] manualmente e instalá-lo diretamente, ou importá-lo para a sua ferramenta de gerenciamento preferida.

## Installomator

A versão 0.7 do [Installomator](https://github.com/Installomator/Installomator) inclui um rótulo para o diálogo.

Para instalar o "dialog" usando o Installomator, basta baixar e executar o arquivo `./Installomator.sh dialog` ou importar o script do Installomator para a sua ferramenta de gerenciamento preferida.
