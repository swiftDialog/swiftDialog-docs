# Contribuindo

Contribuições são muito bem-vindas! Existem muitas maneiras de apoiar este projeto, seja por meio de código, feedback ou apoio financeiro.

## Contribuições de código

Se você gostaria de contribuir com código, por favor, faça um "fork" do repositório, crie um ramo (branch) e envie uma solicitação de alteração (pull request).

Ao enviar solicitações de alteração (pull requests), por favor, tente seguir a estrutura de código existente para garantir a consistência interna. Não sou excessivamente rigoroso em relação à formatação, desde que o código compile, embora eu possa pedir que você organize melhor o código se ele estiver muito confuso.

## Relatando Problemas

- **Sugestões de funcionalidades:** Se você tiver uma ideia para uma nova funcionalidade, mas não puder implementá-la por conta própria, por favor, registre uma solicitação e eu adicionarei à lista de prioridades.
- **Relatórios de erros:** Se você encontrar um erro, por favor, registre-o como um problema, descrevendo como reproduzir o erro.

[Clique aqui para criar um novo formulário ou para relatar um problema.](https://github.com/swiftDialog/swiftDialog/issues/new/choose)

## Contribuições financeiras

Se você considera este projeto útil, especialmente se ele contribui para o seu trabalho ou negócio, por favor, considere fazer uma doação financeira. O seu apoio ajuda a manter e desenvolver o projeto continuamente.

- [GitHub Sponsors](https://github.com/sponsors/bartreardon)
- [Me compre um café.](https://www.buymeacoffee.com/bartreardon)

Organizações que utilizam este projeto comercialmente são bem-vindas a patrociná-lo, caso considerem que isso trará benefícios. Não há nenhuma obrigação, e isso não afetará a forma como interajo com ninguém, mas contribui para manter o projeto em andamento.

## Uma reflexão sobre a gentileza

Este é um projeto pessoal que mantenho em meu tempo livre. Se você tiver sugestões de melhorias ou conhecer uma abordagem mais eficaz para algo, adoraria saber — seja por meio de uma solicitação de alteração, um relatório de problema ou apenas um comentário. O que peço é que o feedback seja construtivo e respeitoso.
