## Correções

- #484 - Propriedade restaurada `name=` no texto de ajuda `--messagefont`
- #574 - O seletor de data e hora foi configurado corretamente para `--textfield`
- #608 - Opções repetíveis não causam mais erros quando usadas como último argumento
- #630 - `--ontop` respeita o posicionamento das docas
- #690 - Atualizações no arquivo de comandos para a legenda de imagens
- #691 - Renderização do cabeçalho do grupo "Preset5"
- #696 - Corrigido um problema que impedia o funcionamento de `--hidedefaultkeyboardaction`
- #689 - Minimizar/maximizar no modo de inspeção
- Adicionados `boundedBinding` e `setIfInBounds` utilitários aos campos de texto/botões de alternância em cards para evitar falhas do tipo "Índice fora dos limites" ao navegar para fora de cards que contêm campos de entrada
- Migrei de `ForEach(0..<collection.count)` para `ForEach(Array(collection.indices), id: \.self)` para evitar armadilhas relacionadas a índices desatualizados
- Corrigidos `--textfield ...,date` e `--textfield ...,time` para retornar os valores corretamente
- `--alwaysreturninput` retorna resultados selecionados, listados ou em formato JSON em **todos** os caminhos de saída, e não apenas quando um botão é pressionado.
  - Observação: Scripts que dependem do comportamento anterior (que só retornava ao pressionar um botão) podem apresentar resultados diferentes. É possível que seja necessário revisar o código se você estiver utilizando essa funcionalidade


## Melhorias de desempenho

- **Buscas remotas:** Limitadas por tempos máximos de espera (10 segundos) para imagens e arquivos Markdown
- **Decodificação de imagens:** As imagens são decodificadas uma única vez, em vez de a cada renderização
- **Carregamento de SVG/PDF** - Carregue uma vez através de `.task`, em vez de a cada renderização
- **Visualizar medidas** - Utilize `onGeometryChange` em vez de GeometryReader
- **Temporizadores por botão** - Funcionam apenas quando `enableOnTimer` está ativado
- **Análise de JSON:** O processo de análise do JSON é executado apenas uma vez na inicialização, em vez de duas vezes


## Enhancements

### Configuração JSON para argumentos

Muitos argumentos que anteriormente aceitavam apenas valores separados por vírgulas agora podem ser especificados como objetos JSON. Isso oferece um controle mais preciso e é especialmente útil para configurações complexas.

**Argumentos suportados:**
- `--textfield` 
- `--checkbox` 
- `--listitem` 
- `--selecttitle` / `--selectitem`
- `--titlefont` / `--messagefont`
- `--icon` / `--overlayicon`
- `--button1symbol` / `--button2symbol` / `--infobuttonsymbol`

**Example:**

```bash
# Text field with date picker and bounds
dialog --textfield '{"title":"Select Date","date","mindate":"20260901","maxdate":"20260930","format":"+%Y-%m-%d"}'

# Checkbox with icon
dialog --checkbox '{"label":"Enable telemetry","checked":true,"icon":{"sf":"checkmark.circle","colour":"green"}}'

# List item with animated icon
dialog --listitem '{"title":"Download","status":"wait","icon":{"sf":"gear","colour":"blue","animation":"variable"}}'

```

Consulte as páginas de documentação individuais para obter os esquemas JSON detalhados e exemplos.

### Limites do seletor de datas

Os componentes de seleção de data e hora agora suportam limites mínimos e máximos de data, através dos modificadores `mindate=` e `maxdate=`.

```bash
dialog --textfield "Pick a day,date,mindate=20260901,maxdate=20260930"
```

### Modo de Inspeção: Opções Gerais

O modo de inspeção agora suporta um objeto `options` na configuração JSON para controlar o comportamento geral do diálogo:

```json
{
  "options": {
    "moveable": true,
    "ontop": true,
    "resizable": true,
    "windowbuttons": "min,max,close"
  }
}
```


## Depreciações

- O modificador `isdate` para `--textfield` foi descontinuado, sendo substituído por `date` e `time`
- Valores numéricos entre aspas na configuração JSON (por exemplo, `"size": "40"`) agora geram um aviso de descontinuação. Utilize números sem aspas em vez disso
