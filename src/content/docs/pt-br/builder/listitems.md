Adicione uma ou mais `--listitem` entradas

<img width="500" alt="image" src="/builder/builder_listitems.png" />

Clique no ícone `[+]` para adicionar uma nova entrada de item de lista

Clique no ícone de lixeira para remover um item específico da lista

Arraste a barra (☰) localizada à esquerda de uma linha para reorganizar os itens

<img width="500" alt="image" src="/builder/builder_listitems_populated.png" />

## Propriedades

#### Mostrar

Exibe ou oculta a área de itens da lista

#### Ícone

Defina um ícone para o item da lista

Arraste um recurso de imagem ou um pacote de aplicativos para a área de visualização do ícone para definir o valor do ícone

Clique na área de visualização do ícone para exibir a janela pop-up do símbolo SF. A partir daqui, você pode definir o valor e a cor do símbolo SF

<img width="200" alt="image" src="/builder/builder_listitem_sfsymbol.png" />

#### Título

Define o valor do título do item da lista

#### Legenda

Define o valor do subtítulo do item da lista

#### Texto de status

Define o texto de status do item da lista

#### Ícone de status

Define o ícone de status do item da lista para um dos valores de status pré-definidos

Se estiver utilizando o ícone de status `progress`, utilize o controle deslizante para visualizar ou definir o estado inicial de progresso
