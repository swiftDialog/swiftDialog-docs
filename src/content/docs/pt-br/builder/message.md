### Propriedades

As seguintes propriedades podem ser configuradas. Clique no botão "Restaurar" para reverter essas configurações para os valores padrão

#### Alinhamento de texto

Posiciona o texto alinhado à esquerda, ao centro ou à direita

#### Posição vertical

Quando habilitado, a posição vertical é definida como centralizada, em vez de alinhada ao topo

#### Cor

Define a cor da mensagem

#### Fonte em Markdown

Além de digitar a mensagem diretamente, você pode carregá-la de um arquivo Markdown ou de um URL usando o botão "**De arquivo…**" ou o campo "**URL / Carregar**". O editor carrega o conteúdo na visualização em tempo real, enquanto o arquivo JSON/comando exportado faz referência ao arquivo ou URL (para que seja carregado durante a execução). Use a opção "**Editar inline**" para retornar à edição do texto diretamente.

ℹ️ _OBSERVAÇÃO: Não é possível ajustar a fonte._
