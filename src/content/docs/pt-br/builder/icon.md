## Propriedades

#### Ícone

Arraste e solte uma imagem ou aplicativo sobre o ícone correspondente na janela do construtor para definir o valor do ícone

<img width="200" alt="image" src="/builder/builder_icon_drag.png" />

<img width="500" alt="image" src="/builder/builder_icon_drop.png" />

Você também pode usar o botão "Selecionar" para abrir uma janela de seleção de arquivo, ou digitar o nome de um símbolo SF no formato `sf=name` na caixa de texto do valor do ícone (onde `name` é o nome de um símbolo SF válido).

Alternativamente, clique no ícone de visualização para abrir a janela pop-up dos símbolos SF e defina um nome e uma cor para o símbolo SF — o mesmo seletor usado para [itens de lista](/pt-br/builder/listitems/) e [caixas de seleção](/pt-br/builder/checkboxes/). O ícone de sobreposição usa o mesmo seletor.

#### Visível

Define se o ícone é visível ou não

#### Centralizado

Reposiciona o ícone, movendo-o da barra lateral esquerda para uma posição centralizada acima da área `--message`

#### Tamanho do ícone

Defina o tamanho do ícone em pontos

ℹ️ _OBSERVAÇÃO: Se o tamanho definido não couber no espaço disponível, o ícone será redimensionado para o tamanho máximo que se ajuste a esse espaço._

#### Ícone Alpha

Defina o nível de transparência do ícone. 0 = transparente, 1 = opaco

#### Camada

Defina a sobreposição do ícone

ℹ️ _OBSERVAÇÃO: A sobreposição (overlay) não está disponível quando um ícone é exibido no modo centralizado._
