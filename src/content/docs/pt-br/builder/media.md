### Vídeo

Clique em "Selecionar" para abrir a janela de seleção de arquivo

Selecione "Ativar" para exibir a área de visualização do vídeo

Selecione "Reprodução automática" para definir o valor da reprodução automática

### Web

Use o botão para ativar ou desativar a visualização do conteúdo da web

Insira o URL desejado para exibir o conteúdo
