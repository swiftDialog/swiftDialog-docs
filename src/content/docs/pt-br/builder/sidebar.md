## Propriedades

#### Caixa de informações

Defina o texto que será exibido na área da caixa de informações.

Utilize Markdown para formatar o conteúdo do texto. Você também pode carregar a caixa de informações a partir de um arquivo Markdown ou de uma URL, usando o botão "**De arquivo…**" ou o campo "**URL / Carregar**" — o editor carrega o conteúdo na visualização, enquanto a exportação faz referência ao arquivo ou à URL. Use a opção "**Editar inline**" para retornar à edição do texto diretamente.

#### Visível

Define se a barra lateral está visível ou não

#### Texto informativo

Define o conteúdo do texto informativo

ℹ️ _OBSERVAÇÃO: Quando `--infobutton` é utilizado, `--infotext` não será exibido._
