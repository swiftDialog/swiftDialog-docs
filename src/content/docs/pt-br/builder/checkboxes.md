Adicione um ou mais itens de caixa de seleção à janela de diálogo

<img width="500" alt="image" src="/builder/builder_checkbox.png" />

Clique no botão `[+]` para adicionar uma nova entrada à lista de itens de seleção

Clique no ícone de lixeira para remover uma opção de caixa de seleção

Arraste a barra (☰) localizada à esquerda de uma linha para reorganizar os itens


<img width="500" alt="image" src="/builder/builder_checkbox_populated.png" />

## Propriedades

#### Formatar a saída

Defina se a saída da caixa de diálogo deve usar o formato JSON ou não

#### Botão de ajuda

Clique para ver a `--checkbox` descrição de ajuda

#### Mostrar

Habilita ou desabilita a exibição da caixa de seleção

#### Estilo de interruptor

Permite o estilo de botão alternador. Quando não selecionado, é utilizado o estilo de caixa de seleção

#### Ícone

_Disponível apenas quando o estilo `switch` está habilitado._

Arraste uma imagem ou um pacote de aplicativos para a visualização do ícone para definir o valor do ícone

Clique na área de visualização do ícone para definir um símbolo e uma cor do tipo SF

#### Etiqueta

Defina o texto do rótulo da caixa de seleção

#### Nome

Defina o valor do atributo "name" para a caixa de seleção. Quando utilizado, a propriedade `name` será exibida na saída para identificar a caixa de seleção, em vez do rótulo

#### Verificado

Define o estado inicial da caixa de seleção

#### Desabilitado

Define o estado de desabilitado da caixa de seleção
