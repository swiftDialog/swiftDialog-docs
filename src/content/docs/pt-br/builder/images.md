Defina uma ou mais imagens para serem exibidas

<img width="500" alt="image" src="/builder/builder_images.png" />

Clique no botão `[+]` para criar uma nova entrada de imagem. Você pode fazer isso uma ou mais vezes

Clique no botão "Selecionar" para abrir uma janela de seleção de arquivos e escolher uma imagem para exibir.

**Alternativamente:**

Arraste uma imagem do Finder para a visualização da imagem para adicionar ou substituir o recurso de imagem para aquela entrada

**OU**

Selecione uma ou mais imagens no Finder e arraste-as para a área da lista de imagens na janela do Builder. Uma nova entrada será adicionada para cada imagem


<img width="500" alt="image" src="/builder/builder_images_populated.png" />

Clique no `≡` botão de arrastar ao lado da visualização da imagem para reorganizar os itens na lista

Clique no ícone da lixeira para excluir uma entrada de imagem

## Propriedades

#### Legenda

Define uma legenda para ser exibida abaixo da imagem especificada

#### Mostrar

Exibe ou oculta a imagem

#### Reprodução automática

Permite a reprodução automática de imagens quando várias imagens estão sendo exibidas

Defina o valor de reprodução automática como o número de segundos que cada imagem será exibida. Um contador regressivo aparecerá como um guia visual para indicar quando a próxima imagem na sequência será mostrada.
