title: Preferências e configurações
description: Compreendendo a abordagem do swiftDialog em relação à configuração
translationSynced: 2026-11-25T11:51:29+00:00
---

Não existem.

O Dialog foi projetado para ser o mais simples possível. Qualquer configuração é feita por meio de opções de linha de comando, que são o principal método de interação.

Não existe nenhuma lógica além do que é necessário para exibir a caixa de diálogo.

A intenção é que você, como administrador responsável pela implementação dessa ferramenta, escreva a lógica necessária para chamar a ferramenta e processar o resultado, utilizando a linguagem de programação de sua preferência.
