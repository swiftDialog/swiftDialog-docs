## Exemplo de Início Rápido

```bash
# Notificação simples
dialog --title "Bem-vindo" \
       --message "Olá do swiftDialog!" \
       --icon "SF=star.fill"

# Formulário de informações do usuário
dialog --title "Informações do usuário" \
       --message "Insira seus dados:" \
       --textfield "Nome,prompt=Digite seu nome" \
       --textfield "E-mail,prompt=Digite seu e-mail" \
       --button1text "Enviar"

# Indicador de progresso
dialog --title "Instalando software" \
       --message "Aguarde enquanto configuramos tudo..." \
       --progress 10 \
       --progresstext "Iniciando instalação..."
```
